## 연구설계·근거검증 공통 기준

SSU_논문·SSU_문제정의·SSU_실증설계·SSU_원문검수의 절차를 공통 가이드에 반영했습니다. 연구방법과 산출형식을 별도로 선택하고, 공백–RQ–기여–검증–반증 및 문헌 ID–판본–페이지–주장 연결을 기록합니다.

기존 본문·트랙·단계별 지침과 추가 문서 3편을 같은 기준으로 검토했습니다. 공통 기준은 19번, 문제정의·실증설계·원문검수의 상세 양식은 20·21·22번에서 관리합니다. 사례의 장수·학기 수·분석 방법을 필수 기준으로 일반화하지 않으며, 학사요건·서식은 적용 대상과 확인일을 함께 읽습니다. 스킬 원문·도구·비공개 강의를 복사한 것이 아니며, 웹에서 스킬 실행·실제 통계분석·원문검수·사람의 승인을 제공하지 않습니다.

## 사용 순서

1. 현재 단계와 필요한 결과물을 찾습니다. 처음이라면 주제·연구질문부터 시작합니다.
2. 문헌검토로 연구 공백을 확인하고 질문–자료–방법–판단 기준을 연결합니다.
3. 질문에 맞춰 실증·실험 안내를 선택합니다. 혼합연구는 질문과 증거를 구분해 함께 사용합니다.
4. 상세 지침과 프롬프트를 실제 확보한 자료와 함께 사용합니다.
5. 제출 시점에서 일정을 역산하고 본인에게 적용되는 자격·서류를 확인합니다.

장 수·분량·학기 수를 학위 명칭으로 고정하지 않습니다. 범위와 검증 깊이는 연구질문·자료 접근성·지도교수와 합의한 기준에 맞춥니다. 실제 학사 규정 차이는 조건부 참고 자료로 확인합니다.

## 웹 파일과 기존 링크

- GitHub Pages는 `docs/`를 배포합니다. `html/`은 같은 내용의 로컬 열람본입니다.
- 기존 `master.html`·`석사과정.html`은 공통 홈, `phd.html`·`박사과정.html`은 학사·제출 요건으로 연결됩니다. 기존 세부 앵커도 유지합니다.
- 한국어 방법별 주소는 `empirical.html`·`experiment.html`로 연결됩니다. 자동 이동이 꺼져 있어도 이동 링크를 사용할 수 있습니다.
- 기존 Markdown의 학위명이 들어간 파일명은 공유 링크 호환성을 위해 유지합니다. 해당 일정은 적용 조건이 있는 사례입니다.
- 로컬 열람: `python -m http.server 8731 --directory docs` 실행 후 `http://localhost:8731/`을 엽니다.
- 구조·링크 회귀 검사: `python scripts/check_guide.py`. 내용·Markdown 목차 검사: `python scripts/check_content.py`. 별도 Python 패키지는 필요하지 않습니다.

## 근거와 적용 범위

이 자료는 학술총무의 논문작성 실무 자료(2026-09-21 기준)를 AI 도구(Claude)로 재구성한 교보재입니다. 원본은 최정일 교수 강의노트(L1–L11)와 숭실대 실제 학위논문 사례(D01–D06) 등을 근거로 표시하며 갱신됩니다. 원본은 외부 배포하지 않으며 필요하면 학술총무에게 문의합니다. 단계별 지침 31편의 원출처는 기존에 작성된 “석사 논문가이드 플랫폼”이며, 자세한 출처는 [라이브러리 목차](12_단계별_지침_라이브러리/00_목차.md)에 있습니다.

신뢰도·표본 수·적합도 기준과 장 수·분량·집필 순서는 연구설계와 제출 지침에 따라 판단합니다. 원문 근거와 적용 조건을 확인하고 AI는 보조자료로 사용합니다. 학사요건·제출서식·학회 규정은 제출 직전에 최신 공식 공지를 확인하세요.
