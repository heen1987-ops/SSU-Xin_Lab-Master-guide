## 이 자료는 무엇인가

학위논문을 처음 쓰는 석사과정 원우와 박사과정 원우를 위해 만든 오리엔테이션 교보재입니다. 학술총무가 정리해 둔 두 계열의 논문작성 실무 자료 — 경영·정보시스템 계열의 설문/SEM 실증연구와, 공학·컴퓨터공학 계열의 학회지·학위논문 체계 — 를 바탕으로, AI 도구(Claude)를 활용해 재구성한 자료입니다.

**중요 — 이 자료의 성격과 한계**

- 이 자료는 석사·박사과정 원우의 논문작성을 돕고자 만든 기초자료입니다.
- 신뢰도 α, 표본 수, 적합도 기준은 연구설계와 적용 조건을 함께 확인해야 합니다. 장 수·분량·집필 순서도 작성 예시이며, 실제 적용은 공식 지침과 지도교수의 지도를 확인해 정합니다.
- 숭실대·특정 학과의 제출 규정, 각 학회의 투고 규정은 학기·학회마다 바뀔 수 있으므로 제출 직전 반드시 최신 공식 공지를 다시 확인하세요.

## 사용 순서

1. **과정 선택 화면**에서 석사·박사를 고른다. 박사는 [박사과정 가이드](https://heen1987-ops.github.io/SSU-Xin_Lab-Master-guide/phd.html)에서 연구실적 점수제·학술지 사분위·종합시험 27학점 등 석사와 다른 점만 확인한 뒤 석사과정 가이드로 온다. 박사 일정은 [17_박사_예상일정_WBS.md](17_박사_예상일정_WBS.md)를 본다.
2. **석사과정 가이드**의 방법 선택 절에서 내 연구가 실증 트랙인지 실험 트랙인지 판단하고, 일정 절에서 1~4학기 WBS·간트차트의 큰 그림을 잡는다.
3. 트랙을 정했다면 해당 **트랙별 작성가이드**(실증/실험)에서 5장 구성·분량 배분·인용 스타일·최근 사례를 확인한다. 더 깊은 실무는 같은 폴더의 **트랙 폴더**(01_실증트랙_경영IS/ 또는 02_실험트랙_공학컴공/) 01번 파일부터 순서대로 읽는다. 각 파일은 그 단계에서 반드시 답해야 할 질문과 바로 쓸 수 있는 표 양식을 담고 있다.
4. 실제 단계에 들어서면 **[12_단계별_지침_라이브러리/](12_단계별_지침_라이브러리/)**에서 해당 단계의 지침을 찾아 점검표로 쓴다 — [00_목차.md](12_단계별_지침_라이브러리/00_목차.md)에서 전체 31편의 목록과 용도를 한눈에 볼 수 있다.
5. 실제 작업(주제 확정, 설문 문항 설계, 실험 설계, 초고 집필 등)에서 AI 도구를 쓸 때는 [15_단계별_예시_프롬프트.md](15_단계별_예시_프롬프트.md)의 단계별 프롬프트를 그대로 복사해 쓴다. 지켜야 할 원칙은 [09_AI로_논문작성하기.md](09_AI로_논문작성하기.md)에 있다.
