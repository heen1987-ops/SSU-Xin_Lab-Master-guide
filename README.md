## 웹에서 읽기

[논문 가이드](https://heen1987-ops.github.io/SSU-Xin_Lab-Master-guide/)에서 연구 단계, 실증·실험 안내, 연구설계·근거검증, 학사 요건을 확인할 수 있습니다. 웹은 기본 브랜치에 반영되어 배포된 판본입니다. 작업 브랜치의 새 핸드북은 [로컬 열람본](docs/handbook.html) 또는 위 Markdown 링크로 확인합니다.

웹에는 검색·테마 전환·내용 복사·체크리스트 저장 기능이 있습니다. 저장되는 체크 상태는 개인 브라우저 설정이며 학생별 검토 기록이나 학술적 승인 상태가 아닙니다.

## 공통 원칙

학위과정, 연구방법, 산출형식은 별도로 기록합니다. 장수·분량·표본 수·SEM·특정 저널을 학위명만으로 정하지 않습니다. 연구 범위와 검증 깊이는 실제 질문·근거·지도교수와 합의한 기준으로 판단합니다.

문헌 후보·원문 독해·주장 검증·분석 실행·파일 검사·사람의 확인을 구분합니다. 미확보 자료나 실행하지 않은 결과를 채워 넣지 않습니다. 학술총무의 검토와 AI 자기점검은 공식 심사·학사 판정을 대신하지 않습니다.

공개 저장소에는 일반 안내와 빈 서식을 둡니다. 작성한 학생별 원고·현황·실제 의견은 연구실의 접근이 제한된 공간에 보관합니다.

## 출처와 유지관리

기존 자료는 학술총무의 실무 자료와 강의자료·학위논문 사례를 바탕으로 정리되었습니다. 이번 개편은 통합 `ssu-paper`의 학위·집필·검토 절차를 적용했습니다. 원자료의 기존 출처와 확인일을 유지하며 스킬 본체·비공개 원문을 복제하지 않습니다.

[출처·확인 범위](handbook/05_문서관리와_출처.md)에 2026-10-15 대조한 공식 페이지와 미확인 항목을 기록했습니다. 학사 자격·서식·기한은 본인에게 적용되는 최신 공식 공지를 확인하세요.

관리자는 [생성·검사 안내](scripts/README.md)를 따릅니다. 로컬 열람은 `python -m http.server 8731 --directory docs` 실행 후 `http://localhost:8731/`에서 가능합니다.
