# JCR·Scopus Q1·Q2 판정기록 지침

핵심: Q1·Q2는 학술대회 등급이나 개별 논문의 품질등급이 아니다. 특정 연도·데이터베이스·주제분야에서 계산된 학술지의 상대적 Quartile이다.

## 1. 판정 전에 구분
- JIF Quartile과 JCI Quartile: Clarivate Journal Citation Reports가 각각 제공하는 주제분야별 위치로 서로 구분
- CiteScore Quartile: Scopus Sources의 CiteScore Percentile 기반 위치
- SJR Quartile: SCImago 지표 기반 Quartile로, JCR·CiteScore와 같은 값으로 간주하지 않음
- KCI 등재구분: 국내 학술지의 등재·등재후보 상태로 Q1·Q2와 별도

## 2. Q1·Q2 의미
- Q1: 분야 내 Rank/전체 수의 순위비율이 0 초과 0.25 이하인 첫 구간
- Q2: 순위비율이 0.25 초과 0.50 이하인 다음 구간
- 동률 때문에 각 Quartile에 실제로 정확히 25%의 학술지가 포함되지 않을 수 있음
- 같은 학술지가 여러 주제분야에 속하면 분야마다 Rank·Percentile·Quartile이 다를 수 있음
- 최신 표시값과 논문 게재연도에 대응하는 값이 다를 수 있음
- JCR은 연간 스냅샷이며 CiteScore Tracker는 월별 갱신값이므로 확정 연간 CiteScore Quartile과 구분함
- 지표명과 연도를 생략한 'Q1 저널' 표현은 증빙으로 불충분함

## 3. 판정 기록표
학술지명 | ISSN | 데이터베이스 | 지표명 | 기준연도 | 주제분야 | Rank/전체 수 | Percentile | Quartile | 확인일 | 공식 URL | 증빙파일 | 적용 공고·규정

## 4. 확인 순서
1. 학술지 공식명과 ISSN을 확인한다.
2. JCR, Scopus Sources 또는 KCI 공식 검색에서 직접 찾는다.
3. 기준연도와 주제분야를 선택한다.
4. Rank, Percentile, Quartile을 함께 기록한다.
5. 화면 또는 내보낸 자료를 날짜가 포함된 증빙파일로 보존한다.
6. 졸업·장학·실적 공고가 요구하는 데이터베이스와 판정연도를 대조한다.
7. 다중 분야·경계값·색인변경은 적용 공고의 담당부서에 공식 판정을 확인하고 본인의 지도교수와 연구일정을 조정한다.

## 5. 숭실대 연구실적과의 관계
- 일반대학원의 박사 연구실적 최소요건은 계열별 색인·게재건수 기준으로 제시된다.
- 더 강화된 학과 내규가 있으면 학과 기준을 적용한다.
- Q1·Q2가 졸업요건인지, 장학·성과평가 기준인지 해당 공고에서 분리해 읽는다.
- 주저자·교신저자, 숭실대 소속, 게재확정 인정, 게재일 기준은 사업마다 다를 수 있다.
- ITPM 전공계열과 개별 적용기준은 현행 규정·학과 내규와 적용 공고의 담당부서 판정으로 확정하고 본인의 지도교수와 준비계획을 조정한다.

## 6. 금지사항
- 출판사 홈페이지의 홍보문구만으로 Quartile 확정
- JCR Q와 CiteScore Q를 구분하지 않고 혼용
- 여러 분야 중 가장 높은 Quartile만 근거 없이 제출
- Scopus 검색의 Highest percentile만 제출하고 적용 주제분야를 생략
- CiteScore Tracker를 확정 연간 Quartile처럼 사용
- 현재 Quartile을 과거 게재연도의 값처럼 사용
- 학술대회 순위·채택률을 Q1·Q2로 표현
- 색인중단·저널명 변경·ISSN 변경을 확인하지 않음

## 완료기준
- 지표·연도·분야·확인일이 포함된 판정기록이 있음
- 공식 데이터베이스 URL과 증빙이 보존됨
- 학교·학과·장학·성과평가 중 어디에 적용하는지 명시됨
- 애매한 기준은 제출 전에 담당부서와 지도교수에게 확인함
