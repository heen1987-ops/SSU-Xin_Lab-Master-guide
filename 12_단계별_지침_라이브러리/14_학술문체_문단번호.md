# 학술문체·문단번호 지침

목표: 주장강도를 증거에 맞추고 각 문단·번호·표현이 하나의 논증 구조로 읽히게 정리한다.

## 학술문체 원칙
- 정확성: 관찰·분석·추론·인과를 구분한다.
- 객관성: 작성자의 확신보다 근거의 강도로 주장한다.
- 간결성: 중복 수식어와 불필요한 배경을 줄인다.
- 추적성: 인용·표·그림·분석 위치를 확인할 수 있게 한다.
- 일관성: 제목·초록·RQ·변수·표·결론에서 같은 용어를 쓴다.
- 절제성: 표본과 설계가 허용하는 범위를 넘어 일반화하지 않는다.

## 권장 어체
- 분석 결과, A는 B와 유의한 관련성을 보였다.
- 실험군은 통제군보다 평균 정확도가 높게 나타났다.
- 가설 2는 통계적으로 지지되지 않았다.
- 이 결과는 A가 B의 선행요인일 가능성을 시사한다.
- 다만 횡단면 자료이므로 인과관계로 단정하기 어렵다.

## 지양 표현
- "필자는 생각한다" → "본 연구는 ~로 해석한다."
- "매우 획기적이다" → 비교기준과 수치 제시
- "완전히 증명하였다" → "지지하였다 / 관련성을 확인하였다."
- "당연히, 명백히" → 근거·조건 직접 제시
- "~인 것 같다" → "~로 나타났다 / ~로 해석할 수 있다."

## 한 문단의 구조
1. 핵심문장: 문단이 답할 하나의 주장
2. 근거: 선행연구·데이터·표·그림·분석수치
3. 해석: 근거가 현재 연구에서 의미하는 바와 적용범위
4. 연결: 연구질문 또는 다음 문단과의 관계

문단은 번호를 붙이는 행정 단위가 아니라 하나의 주장을 완결하는 논증 단위다.

### 문단 기능별 자기점검 질문

| 요소 | 역할 | 자기점검 질문 |
|---|---|---|
| 핵심문장 | 문단이 주장하거나 설명할 한 가지 중심내용 제시 | 첫 1–2문장만 읽어도 문단의 역할을 알 수 있는가? |
| 근거 | 선행연구·수치·표·그림·관찰결과로 핵심문장을 지지 | 출처와 증거 위치를 추적할 수 있는가? |
| 해석 | 근거가 현재 연구에서 의미하는 바와 적용범위 설명 | 결과를 반복하지 않고 의미를 밝혔는가? |
| 연결문장 | 연구질문 또는 앞뒤 문단과의 논리적 관계 명시 | 다음 문단이 갑자기 시작되지 않는가? |

## 장·절·항·목·문단
- 제1장: 논문의 최상위 구성
- 제1절: 한 장 안의 주요 논점·절차·결과 묶음
- 1.: 절 안에서 독립적으로 설명할 세부 주제인 항
- 가.: 항을 더 세분하는 목
- 문단: 하나의 중심생각을 전개하는 본문 단위이며 일반적으로 번호 없음
- 더 낮은 수준이 꼭 필요하면 1) → 가) → (1) → (가) 순서를 사용할 수 있으나 학교 양식을 우선한다.

## 번호 원칙
- 같은 수준에는 같은 형식을 사용한다.
- 상위항목이 하나뿐이면 불필요한 하위번호를 만들지 않는다.
- 번호가 지나치게 깊어지면 절·항을 다시 묶는다.
- 실제 번호·들여쓰기·글꼴·간격은 숭실대학교 ITPM 제공 양식과 지도교수 지침을 따른다.

## 완료기준
- 인과·상관·예측 표현을 구분함
- 모든 문단에 중심문장과 근거가 있음
- 장·절·항·목 번호가 일관됨
- 표·그림·수식이 본문에서 모두 호출됨
- 본문 인용과 참고문헌이 양방향 일치함
- 국문·영문 초록의 수치·결론이 일치함
