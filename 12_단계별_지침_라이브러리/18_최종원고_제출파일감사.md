# 최종 원고·제출파일 감사 지침

원칙: 최종 검수는 한 번의 완독으로 끝내지 않는다. 논리, 증거, 숫자, 인용, 형식, 윤리와 파일을 서로 다른 목적으로 나누어 점검하고 본인의 지도교수 확인 후 제출한다.

## PASS 1 · 논리 감사
- 제목–초록–문제–Gap–RQ–설계–결과–기여가 연결됨
- 각 장·절의 첫 문장이 역할을 밝히고 마지막 문장이 다음 논리로 연결됨
- 결과에 없는 주장이 서론·초록·결론에 없음
- 기각·실패 결과가 누락되거나 반대로 해석되지 않음
- 연구범위와 한계가 실제 설계에 맞음

## PASS 2 · 증거·숫자 감사
- 모든 RQ·가설에 대응하는 결과표·그림이 있음
- 표본수·제외수·기간·반복횟수가 전 장에서 일치함
- 계수·부호·효과크기·CI·p값·성능 수치를 원출력과 대조함
- 표·그림 제목, 단위, 범례, 주석, 출처와 오차막대 정의가 있음
- 표·그림이 저장된 코드·로그에서 재생성됨

## PASS 3 · 인용·참고문헌 감사
- 본문 인용이 참고문헌에 있고 참고문헌의 모든 자료가 본문에서 인용됨
- 정의·척도·방법·데이터·Baseline은 가능한 원출처를 인용함
- 직접인용은 정확한 위치와 인용부호·블록형식을 적용함
- APA 또는 IEEE 한 체계를 유지하고 목표 양식과 충돌하지 않음
- DOI·URL·저자·연도·학술지·권·호·쪽이 원자료와 일치함

## PASS 4 · 문체·표현 감사
- 한 문단에 하나의 핵심기능이 있음
- "영향·효과·원인·입증"의 강도가 설계와 근거에 맞음
- 동일 개념·변수·기술·약어에 같은 명칭을 사용함
- 중복 수식어, 홍보어, 모호한 대명사와 불필요한 반복을 제거함
- 국문·영문 제목·초록·키워드의 의미와 수치가 일치함

## PASS 5 · 학교 형식 감사
- 최신 학교·학과 템플릿을 기준으로 표지·인준·목차를 확인함
- 장·절·항·목 번호, 글꼴, 간격, 여백, 페이지 체계가 일치함
- 목차·표목차·그림목차의 제목·번호·페이지가 본문과 일치함
- 표·그림·수식 번호가 중복·누락 없이 본문에서 호출됨
- 초록·감사의 글·부록·참고문헌·서명·저작권 등 요구요소가 있음

## PASS 6 · 윤리·행정 감사
- 윤리승인·동의·데이터 권리·도구 사용·저자기여 고지가 맞음
- 표절검사 결과와 필요한 소명·수정이 완료됨
- 심사의견 반영표가 완료되고 미반영 항목에 근거가 있음
- 제출 일정·서류·파일형식·서명·인쇄수량·업로드 절차를 확인함
- 공식 요건은 당해 공지와 담당 절차로, 연구 핵심 결정과 제출본은 본인의 지도교수와 최종 확인함

## PASS 7 · PDF·인쇄·보관 감사
- Word/HWP 원본과 PDF를 별도로 열어 페이지 수를 비교함
- 글꼴 깨짐, 수식 잘림, 그림 저해상도, 표 분리, 빈 페이지를 확인함
- 외부 링크·목차 링크·북마크가 필요한 범위에서 작동함
- 흑백 인쇄에서도 표·그림 구분이 가능함
- 파일명·버전·제출처가 명확하고 제출본과 증빙을 별도 백업함

## 제출 직전 중단 신호
- 지도교수 최종 확인 전임
- 초록과 제4장의 표본수·결론이 다름
- 표와 본문의 수치·가설판정이 다름
- 심사의견 반영표에 미처리 핵심항목이 있음
- 인준·서명·윤리·표절·공식서류가 불완전함
- 제출 PDF를 실제로 열어보지 않음

## 완료기준
- 7개 감사 PASS를 목적별로 분리하여 완료함
- 제출 직전 중단 신호가 하나도 없음
- 다른 장치에서 최종 PDF와 보관본을 정상적으로 열 수 있음
- 본인의 지도교수가 원고 완성도와 내부 제출 준비도를 확인하고, 공식 접수는 당해 공지와 담당부서 절차에 따라 완료함
