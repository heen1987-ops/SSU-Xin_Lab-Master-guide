# 실증논문 지침

목표: 실제 현상의 변수 관계·영향·메커니즘·경계조건을 타당한 자료와 통계추론으로 검증한다.

실제 집필·확정: 제3장 연구설계 → 제4장 연구결과 → 제5장 결론 → 제2장 이론·선행연구 → 제1장 서론

## 권장 흐름
문제·Gap → 이론 → 연구모형 → RQ·가설 → 조작적 정의 → 표본·자료수집 → 신뢰도·타당도 → 가설검증 → 강건성 → 결론

## 제2장
- 핵심 개념의 개념적 정의와 유사개념의 경계
- 변수 관계를 설명하는 이론적 메커니즘
- 관계의 방향을 뒷받침하거나 반박하는 선행연구
- 매개·조절효과의 이론적 이유
- 대상·맥락·방법·결과 불일치에서 도출한 Gap
- 제3장의 모든 변수·가설·척도 선택에 대응하는 근거

## 제3장
- 연구모형–RQ–가설–분석모형 대응표
- 각 가설에서 추정하려는 효과 또는 관계(estimand)와 비교대상
- RQ별 추론목표: 효과 탐지 / 의미 없는 효과 배제 / 목표 정밀도 / 예측성능 추정
- 모집단·표본·표집방법·목표 표본수·제외기준·종료규칙
- 결과 확인 전 정한 최소 의미효과와 기대효과의 근거·불확실성
- 변수별 조작적 정의·문항·척도·원출처·코딩
- 번역·역번역, 전문가 검토, 파일럿 계획
- 자료수집 시점·절차·윤리·개인정보 처리
- 결측·이상치·불성실응답·공통방법편의 처리
- 신뢰도·수렴/판별타당도·다중공선성 점검
- 주 분석, 통제변수, 매개·조절, 추가·강건성 분석계획
- 가능하면 자료를 보기 전에 가설·주 분석·제외·결측 처리계획을 날짜와 함께 고정

## 보고표준 라우팅
- 사회·행동 정량연구는 APA JARS–Quant로 표본·측정·분석·결과의 누락을 점검한다.
- 보건·역학의 코호트·환자대조군·횡단면 관찰연구에 해당할 때만 STROBE를 함께 검토한다.
- 일반 설문이라는 이유만으로 STROBE를 기계적으로 적용하지 않는다.
- 보고지침은 설계의 타당성이나 논문 품질을 인증하는 점수표가 아니다.

## 제4장 제시 순서
자료 정제 → 표본특성 → 기술통계 → 신뢰도·타당도 → 상관관계 → 가설검증 → 매개·조절 → 추가·강건성 분석 → 예상 밖 결과

## 결과 보고
- 표본수와 제외·결측 처리 결과
- 계수 또는 추정치, 표준오차, 효과크기, 신뢰구간, 정확한 p값
- 모형 적합도·설명력과 가정 점검
- 유의하지 않거나 반대 방향인 결과도 동일 기준으로 보고
- 상관관계와 인과효과를 구분하고 설계가 허용하는 범위에서 해석
- p값은 가설의 참일 확률·효과크기·실무 중요도가 아니며 임계값만으로 결론을 정하지 않음

## 핵심 위험
- 내생성·역인과·누락변수
- 편의표본·비응답·생존자 편향
- 동일시점·동일응답자의 공통방법편의
- 척도 수정 후 타당도 미확인
- 유의한 모형만 선택하는 다중검정·p-hacking
- 결과 확인 후 가설·제외기준을 바꾸는 사후합리화

## 완료기준
- 모든 가설에 이론 근거·측정·분석·결과·결론이 연결됨
- 표·본문·부록의 수치와 표본수가 일치함
- 대안설명과 적용범위를 명시함
- 데이터 정제·분석 코드 또는 로그로 결과를 재생성 가능함
- 본인의 지도교수가 결과해석과 전체 원고를 확인함
