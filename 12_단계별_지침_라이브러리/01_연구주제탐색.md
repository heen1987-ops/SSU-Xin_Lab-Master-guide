# 연구주제 탐색 지침

적용: 석사·박사 공통 / 연구주제·방법·범위: 본인의 지도교수와 확정

목표: 학술적·실무적 차별성을 검증할 수 있고 학위 일정 안에서 완료 가능한 연구문제를 근거로 확정한다.

## 기본 흐름
관심영역 → 관찰한 현상 → 해결할 문제 → 선행연구 → Research Gap → 연구질문(RQ) → 예상 기여 → 자료·방법 → 실행가능성 → 지도교수 확정

## 핵심 정의
- 연구주제: 대상·현상·관계를 일정 범위로 좁힌 연구영역
- 연구문제: 현실 또는 지식체계에서 아직 해결되지 않은 구체적 문제
- Research Gap: 선행연구의 미검증·불일치·경계·방법상 공백
- 연구질문: 자료와 방법으로 답해야 하는 명시적 질문
- 연구기여: 결과가 기존 이론·방법·기술·실무를 바꾸는 지점
- 논문제목: 연구가 끝난 뒤 실제 수행내용을 압축한 최종 문장

## 좋은 주제의 네 조건
1. 중요성: 지금 답할 학술적·사회적·산업적 이유가 있다.
2. 미해결성: 기존 연구가 충분히 설명하지 못한 부분이 있다.
3. 검증 가능성: 데이터·실험·분석으로 답할 수 있다.
4. 완료 가능성: 일정·윤리·비용·역량 안에서 수행할 수 있다.

## 후보주제 증거 비교표
항목 | 후보 A | 후보 B | 후보 C | 확인 근거
---|---|---|---|---
학술적 차별성 | 확인/보완/미확인 |  |  | 가장 가까운 선행연구와 달라지는 주장
실무적 차별성 | 확인/보완/미확인 |  |  | 현재 업무기준과 바뀌는 의사결정·성과
Gap 근거 | 확인/보완/미확인 |  |  | 핵심문헌의 불일치·한계·경계조건
설계 구별력 | 확인/보완/미확인 |  |  | 기존 설명과 새 주장을 구별하는 비교·측정
자료 접근 | 확보/조건부/불가 |  |  | 표본·자료·장비·실험환경의 실제 접근 증빙
윤리·권리 | 가능/조건부/불가 |  |  | IRB·동의·개인정보·라이선스 조건
일정 안전성 | 가능/조건부/불가 |  |  | 파일럿·재분석·지도교수 검토시간을 포함한 역산표
실패 해석 | 가능/제한/불가 |  |  | 기각·무효과·성능미달 시 남는 학술적 해석

## 후보 제외·보완 기준
- 자료 접근 또는 윤리·권리 확보가 불가능한 후보는 제외한다.
- 학술적·실무적 차별성 중 어느 것도 증거로 설명되지 않으면 주제를 재정의한다.
- 핵심 설계가 기존 설명과 새 주장을 구별하지 못하면 파일럿 전에 보완한다.
- 일정상 지도교수 검토·재분석 기간을 확보하지 못하면 범위를 축소한다.
- 최종 후보와 보완조건은 비교표와 근거자료를 바탕으로 본인의 지도교수가 결정한다.

## Gap 유형
- 대상 Gap: 특정 산업·조직·집단·국가에서 아직 검증되지 않음
- 맥락 Gap: 기술·정책·환경 변화로 기존 설명의 경계가 달라짐
- 관계·메커니즘 Gap: 왜·언제·누구에게 작동하는지 불명확
- 불일치 Gap: 선행결과의 방향·크기·유의성이 충돌
- 방법 Gap: 자기보고·횡단면·소표본·약한 Baseline 등 기존 설계의 한계
- 이론·기술 Gap: 기존 이론의 설명력 또는 기존 시스템의 성능·공정성 한계

"국내 연구가 부족하다", "최근 중요해졌다", "관련 연구가 많지 않다"만으로는 충분한 Gap이 아니다.

## 연구질문 예시
- 실증: A는 B와 어떤 관계를 보이는가? / M이 매개하는가? / Z에 따라 효과가 달라지는가?
- 실험: 처치 X는 통제조건보다 Y를 개선하는가? / 제안방법은 동일 조건에서 Baseline보다 우수한가?

## 후보주제 점검
- 학술적 중요성과 Gap이 명확한가?
- RQ마다 필요한 자료와 분석·실험이 연결되는가?
- 데이터·참여자·실험환경에 접근 가능한가?
- 실패·기각 결과도 학술적으로 해석 가능한가?
- IRB·개인정보·데이터 권리를 확인했는가?
- 파일럿과 수정시간을 포함해 일정 안에 끝낼 수 있는가?
- 학회·학술지 후속성과로 확장 가능한가?

## 지도교수 검토용 1페이지
- 임시 제목과 문제정의 한 문장
- 핵심 Gap과 근거문헌 3–5편
- 연구질문·가설 또는 실험질문
- 연구유형과 핵심방법
- 대상·데이터·실험환경 접근 가능성
- 예상 결과가 아닌 예상 기여
- 가장 큰 위험 3개와 대안
- 이번 회의에서 결정받을 질문 최대 3개

## 완료기준
- 가장 가까운 선행연구·기존 실무 기준과 본 연구의 차이가 한 문장으로 구분됨
- Gap–RQ–자료–방법–예상기여가 서로 대응함
- 자료 접근·윤리·권리·일정의 불가조건이 없음
- 기각·무효과·성능미달 결과도 해석 가능한 설계임
- 본인의 지도교수가 주제·범위·연구유형과 보완조건을 확정함
