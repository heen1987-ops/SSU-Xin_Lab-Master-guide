# 체계적 문헌검색·선별기록 지침

적용: 석사·박사 공통 / 목적: 검색 결과를 많이 모으는 것이 아니라 핵심문헌이 어떤 기준으로 포함·제외되었는지 재현 가능하게 남긴다.

범위 주의:
- 일반 학위논문의 제2장도 검색식·검색일·선별근거를 남기되 이를 자동으로 '체계적 문헌고찰'이라 부르지 않는다.
- 논문 자체가 체계적 문헌고찰·메타분석이면 PRISMA 2020과 해당 확장판을 적용한다.
- PRISMA 흐름도와 체크리스트는 일반 서술형 선행연구 장의 의무 형식이 아니다.

## 1. 검색 전 범위 잠금
- 연구문제를 대상·현상/개입·비교·결과·맥락으로 분해한다.
- 반드시 포함할 개념과 제외할 동음이의어를 구분한다.
- 검색 대상 데이터베이스, 언어, 기간, 문헌유형, 학문분야를 정한다.
- 고전 이론·원척도·원방법 문헌은 기간 제한과 별도로 추적한다.
- 범위와 검색 종료시점은 본인의 지도교수와 확인한다.

## 2. 검색어 블록 작성
- 개념마다 대표용어, 유사어, 약어, 철자변형, 상위·하위어를 만든다.
- 같은 개념의 용어는 OR, 다른 개념 블록은 AND로 연결한다.
- 제목·초록·키워드 필드와 주제어 색인을 데이터베이스별로 조정한다.
- 너무 좁으면 핵심논문이 누락되고 너무 넓으면 선별 불가능하므로 대표문헌이 검색되는지 시험한다.

검색식 기록표:
검색일 | 데이터베이스 | 검색필드 | 전체 검색식 | 기간·언어 필터 | 결과 수 | 검색자 | 비고

## 3. 파일럿 검색
1. 이미 알고 있는 핵심문헌 5–10편이 결과에 포함되는지 확인한다.
2. 상위 결과 30–50건을 읽어 새로운 용어와 불필요한 용어를 찾는다.
3. 검색식 변경 전·후의 결과 수와 대표문헌 회수 여부를 비교한다.
4. 최종 검색식을 날짜와 함께 고정하고 변경이유를 기록한다.

## 4. 포함·제외 기준
- 포함: 연구질문과 직접 관련된 대상·변수·기술·방법·결과를 보고함
- 포함: 원문을 확인할 수 있고 연구설계와 결과가 판독 가능함
- 제외: 연구주제와 다른 맥락 또는 분석단위를 다룸
- 제외: 중복자료, 초록만 존재, 핵심 방법·결과 확인 불가
- 제외: 학술적 근거로 사용하기 어려운 홍보·의견·출처불명 자료
- 품질이 낮다는 이유와 결과가 마음에 들지 않는다는 이유를 혼동하지 않는다.

## 5. 선별 절차
1. 데이터베이스별 결과를 원본 그대로 보존한다.
2. DOI·제목·저자·연도로 중복을 제거하고 제거 수를 기록한다.
3. 제목·초록 단계에서 기준에 따라 1차 선별한다.
4. 원문 단계에서 포함 여부와 구체적 제외사유를 기록한다.
5. 포함문헌의 참고문헌·인용문헌을 역방향·순방향으로 추적한다.
6. 최종 포함문헌을 핵심, 보완, 방법, 반대결과 문헌으로 분류한다.

선별기록표:
문헌 ID | 제목 | 중복 여부 | 제목·초록 판정 | 원문 판정 | 제외사유 코드 | 역할 | 확인자 | 메모

## 6. 문헌 추출표
서지정보 | 목적/RQ | 이론 | 대상·표본 | 자료·기간 | 변수·측정 | 분석/실험 | 핵심결과 | 효과·불확실성 | 한계 | 내 연구와의 연결 | 인용할 페이지

## 7. 검색 종료조건
- 새 검색에서 연구모형·변수·방법을 바꾸는 핵심 개념이 더 이상 나오지 않음
- 주요 상반결과와 대표 방법론 문헌을 포함함
- 모든 RQ·가설·변수·척도·Baseline·Metric에 근거문헌이 연결됨
- 최근 검색일과 최종 업데이트 필요시점을 기록함
- 검색범위와 핵심문헌 구성을 본인의 지도교수가 확인함

## 금지사항
- 결과가 유리한 문헌만 남기기
- 검색식·검색일·제외이유를 기록하지 않기
- 2차 인용만 보고 원출처를 읽은 것처럼 인용하기
- 검색결과 수를 문헌검토의 품질로 간주하기
- 작성 막바지에 새로운 개념을 근거 없이 대량 추가하기

## 완료기준
- 데이터베이스·검색식·검색일·포함·제외기준이 기록됨
- 중복제거 수와 단계별 포함·제외 수를 다시 계산할 수 있음
- 핵심·반대결과·방법론 문헌이 각 RQ와 설계요소에 연결됨
- 제외사유와 인용할 원문 위치가 문헌별로 남아 있음
- 본인의 지도교수가 검색범위와 핵심문헌 구성을 확인함

공식 참고: https://www.prisma-statement.org/prisma-2020
