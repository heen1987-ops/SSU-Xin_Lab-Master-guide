# 설문·측정척도 품질 지침

목표: 문항 수집이 아니라 연구개념을 타당하고 일관되게 측정하는 도구를 설계하고, 응답과정·표본·측정오차를 설명할 수 있게 한다.

## 측정 설계 순서
개념적 정의 → 하위차원 → 조작적 정의 → 원척도 탐색 → 사용권·번역 → 전문가 검토 → 인지면담 → 파일럿 → 본조사 → 측정품질 검증

## 척도 선택
- 연구개념과 원척도의 정의·대상·상황이 실제로 일치하는지 확인한다.
- 인용 횟수보다 개발절차, 타당도 근거, 후속 검증과 현재 맥락 적합성을 본다.
- 원출처, 문항 수, 하위차원, 응답범주, 역문항, 채점방식을 기록한다.
- 축약·삭제·표현수정·응답범주 변경은 새로운 측정도구에 가까워질 수 있음을 고려한다.
- 라이선스·사용허가·구매조건이 있으면 조사 전에 해결한다.

## 번역·적용
- 번역자는 단어보다 개념적 의미와 대상 집단의 표현을 우선한다.
- 번역–역번역만으로 끝내지 않고 전문가 검토와 대상자 인지면담을 수행한다.
- 문화·산업·직무 맥락에서 이해되지 않는 표현과 이중질문을 제거한다.
- 원문·번역문·수정이유·결정자·버전을 대응표로 남긴다.

## 문항 작성 점검
- 한 문항에는 하나의 판단만 포함한다.
- 기간·대상·상황을 필요한 만큼 구체화한다.
- 유도·비난·사회적 바람직성을 높이는 표현을 줄인다.
- 모든 응답자가 알 수 없는 전문용어·약어를 피한다.
- 응답범주의 간격·방향·레이블을 일관되게 유지한다.
- 부정문·이중부정·과도한 역문항을 줄인다.

## 설문 흐름
- 안내·동의 → 선별질문 → 핵심문항 → 보조변수 → 인구통계 → 종료·문의 순서를 검토한다.
- 앞 문항이 뒤 문항을 유도할 가능성과 동일방법편의를 줄인다. **핵심문항 안에서는 예측변수 블록 → 완충 → 결과변수 블록 순서를 기본으로 한다.** 아래 배치표를 연구에 맞게 줄이고 늘려 쓴다.
- 개인정보는 연구에 필요한 최소범위만 수집한다.
- 모바일 화면, 접근성, 예상 응답시간과 중도이탈을 파일럿에서 확인한다.

| 순서 | 섹션 | 포함 개념 | 목적·동일방법편의 조치 |
|---|---|---|---|
| 0 | 안내문 | — | 포괄적 연구 목적만 제시(변수명·가설 방향 비노출), 익명성 고지, 동의 |
| 1 | 스크리닝 | 선별 문항 | 자격 미충족 시 종료 |
| 2 | 조직·응답자 기본 특성 | 통제변수 | 완충문항 겸 통제변수 |
| 3~n | 예측·매개·조절 블록 | 핵심 개념 | 블록 사이에 마커·완충 배치, 섹션명에 개념명 비노출 |
| — | 전환 안내 | — | 심리적 분리("다음은 마지막 부분입니다") |
| n+1 | 결과변수 블록 | 종속 개념 | 예측변수와 분리, 가능하면 2차 파(시점)로 분리 |
| 끝 | 마무리·연락(선택) | — | 2차 파 동의 등 |

이 순서는 자료를 모은 뒤에는 바꿀 수 없다. **동일방법편의 대응의 절반은 설문지를 만드는 시점에 결정된다** — 분석 단계의 진단(단일요인 검사 등)은 이미 생긴 편의를 확인할 뿐 없애지 못한다.

## 동일방법편의 예방 점검

설문 설계를 끝내기 전에 아래 표를 채운다. **미적용 이유 열이 곧 3장 한계 절의 초안이 된다** — 못 한 조치를 그대로 옮기면 된다.

| 조치 | 적용 여부·방법 | 미적용 이유·남는 한계 |
|---|---|---|
| 시간적 분리(파 분리·완충문항) | | |
| 심리적 분리(포괄적 안내문·섹션명 비노출) | | |
| 근접 분리(예측·결과 블록 사이 거리) | | |
| 응답자 분리(예측변수와 결과변수를 다른 사람이 답함) | | 조직당 1인이 답하는 key-informant 설계면 불가 — 그 사실을 명시 |
| 익명성·비식별 | | |
| 척도 형식 다양화 | | |
| 통계적 진단 계획(마커·잠재방법요인·단일요인 검사) | | 진단은 예방을 대신하지 못함 |

**판정에서 자주 틀리는 것 네 가지**

- Harman 단일요인 검사에서 첫 요인의 설명비율이 특정 수치 아래라는 이유로 동일방법편의가 없다거나 제거됐다고 선언하지 않는다. 이 검사는 편의 부재의 증거가 아니다.
- 마커 변수의 선정 기준은 "마커와 실질변수의 관측상관이 0"이 아니라, **적어도 하나의 실질변수와 이론적으로 무관하다는 사전 근거**다. Lindell과 Whitney의 상관기반 마커변수법은 마커와 실질변수 사이에 실제로 관측된 상관을 방법분산 추정치로 삼아 부분상관으로 조정하는 절차이므로, 유의한 관측상관이 나왔다는 사실만으로 마커 선정이 실패한 것이 아니다. 그 상관을 방법분산으로 볼지 실제 관계로 볼지는 자료가 아니라 사전 근거로 판단한다.
- 조직당 1인이 답하는 key-informant 설계는 응답자 분리를 원천적으로 막는다. 이 경우 나머지 조치는 완화책이며, 편의를 제거했다고 쓰지 않고 방법 절에 그 사실을 적는다. 표본설계 결정과 동일방법편의 대응은 서로 영향을 주는 한 쌍의 결정이다.
- 마커 문항은 **자료 수집 전에 선정**하고 결과를 본 뒤 교체하지 않는다. "시설 만족도"처럼 즉석에서 만든 그럴듯한 문항은 예산·규모 같은 실질변수와 개념적으로 얽혀 있을 위험이 있으므로, 전용으로 개발·검증된 마커 척도를 대안으로 검토한다.

**기록 틀 한 줄**: 편의 원천 → 예방 설계 → 실제 시행 → 남는 원천 → 가능한 진단·민감도 → 제한된 결론. 존재하지 않는 다원자료 수집이나 시차 설계를 결과문에 추가하지 않는다. 이미 수집했다면 가능한 진단과 남는 한계를 보고한다.

## 파일럿 기록
- 참여자 특성·수:
- 평균 응답시간·이탈지점:
- 이해가 어려운 문항:
- 무응답·동일응답·극단응답 패턴:
- 신뢰도·요인구조의 예비신호:
- 수정 문항과 수정이유:
- 본조사 전 지도교수 결정:

## 본조사 품질
- 모집단·표집틀·모집채널·응답률과 제외기준을 기록한다.
- 응답시간, 동일응답, 모순응답, 주의문항은 하나의 기계적 기준이 아니라 사전 규칙과 맥락으로 판단한다.
- 제거 전후 결과가 달라지는지 확인하고 제외 수와 사유를 보고한다.
- 결측의 위치·패턴·처리방법을 기록한다.
- 동일시점·동일응답자 자료의 공통방법편의 위험을 설계와 분석에서 다룬다.

## 측정품질 검증
- 문항·차원별 기술통계와 분포
- 내적 일관성만으로 타당도를 대신하지 않음
- 이론에 맞는 요인구조와 대안모형 비교
- 수렴·판별·준거·내용타당도 중 연구에 필요한 근거
- 집단비교가 핵심이면 측정동일성 또는 비교가능성 점검
- 척도 수정 후 수정된 구조의 타당도와 해석범위 재확인

## 표본수 원칙
- "문항당 몇 명" 같은 단일 경험규칙만 사용하지 않는다.
- 주 분석모형, 기대효과, 검정력, 변수 수, 결측·탈락, 집단비교와 측정모형 복잡도를 함께 고려한다.
- 목표 표본수 산정근거와 실제 확보 표본수의 차이를 설명한다.

## 완료기준
- 모든 문항이 개념·하위차원·원출처와 연결됨
- 번역·수정·파일럿·제외 과정의 결정기록이 있음
- 신뢰도뿐 아니라 연구주장에 필요한 타당도 근거가 있음
- 응답품질·결측·공통방법편의와 표본의 한계를 보고함
- 본인의 지도교수가 본조사 착수와 최종 측정모형을 확인함
