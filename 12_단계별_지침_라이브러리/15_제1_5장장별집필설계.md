# 제1–5장 장별 집필 설계 지침

최종 배열: 제1장 → 제2장 → 제3장 → 제4장 → 제5장
실제 집필·확정 권장순서: 제3장 → 제4장 → 제5장 → 제2장 → 제1장

제1·2장의 자료조사와 초안은 초기부터 진행하되, 실제 결과가 확인된 뒤 전체 논리와 기여에 맞춰 최종 확정한다.

## 제1장 서론: 왜 이 연구를 해야 하는가
권장 흐름:
현상·배경 → 구체적 문제 → 기존 연구의 설명 → Research Gap → 연구목적 → RQ·가설 → 대상·범위·방법 개요 → 기대가 아닌 실제 기여 → 논문 구성

반드시 답할 질문:
- 누가 어떤 상황에서 어떤 문제를 겪는가?
- 그 문제가 학술적·실무적으로 왜 중요한가?
- 기존 연구는 무엇을 밝혔고 무엇을 설명하지 못했는가?
- 본 연구는 정확히 무엇에 답하며 어떤 자료와 방법을 쓰는가?
- 실제 결과가 기존 지식에 무엇을 추가하는가?

완료기준:
- 배경이 넓은 산업소개로 끝나지 않고 연구문제로 수렴함
- Gap–목적–RQ–방법–기여가 한 줄씩 대응함
- 결과가 나오기 전에 예측한 성과가 아니라 실제 수행내용을 반영함

## 제2장 이론적 배경·선행연구: 왜 이 관계와 설계가 타당한가
권장 흐름:
핵심개념 정의·경계 → 중심이론 → 변수관계 또는 기술계보 → 합의·불일치 → 적용조건 → Gap → 제3장 설계 연결

절 구성 원칙:
- 개념별 백과사전식 나열보다 연구질문에 필요한 논쟁 단위로 묶는다.
- 각 절 마지막에 "이 검토가 내 연구의 무엇을 결정하는가"를 쓴다.
- 가설·척도·Baseline·Metric·데이터 선택의 원출처를 확보한다.
- 상반 결과와 실패조건을 숨기지 않는다.

완료기준:
- 제3장의 모든 핵심 선택에 제2장의 근거가 있음
- 인용을 제거해도 작성자의 종합·비판·연결 논리가 남음
- 마지막 절이 연구모형·가설·실험설계로 자연스럽게 이어짐

## 제3장 연구설계: 다른 연구자가 어떻게 재현할 것인가
공통 항목:
연구유형 | RQ·가설 | 대상·자료 | 포함·제외 | 변수·처치 | 비교조건 | 절차 | 윤리 | 분석·평가 | 가정·위험 | 재현정보

실증논문:
- 모집단·표본·표집·목표 표본수 근거
- 개념적·조작적 정의, 척도 원출처와 코딩
- 신뢰도·타당도·공통방법편의·내생성 대응
- 주 분석, 통제변수, 매개·조절, 강건성 계획

실험논문:
- 데이터·처치·통제·Baseline·Metric
- 동일 비교조건, 분할·누수 방지, 반복·Seed
- 하드웨어·소프트웨어·버전·Hyperparameter
- Ablation·Sensitivity·Robustness·실패기준

완료기준:
- 실제 실행 전에 절차·분석·제외·중단 기준을 설명할 수 있음
- 파일럿 결과와 지도교수 결정이 반영됨

## 제4장 연구결과: 연구질문에 어떤 증거가 나왔는가
권장 흐름:
자료·실험 현황 → 품질점검 → 기술결과 → 주 검증 → 추가검증 → 실패·기각·예상 밖 결과 → 장 요약

작성 원칙:
- 표 출력 순서가 아니라 RQ·가설 순서로 작성한다.
- 추정치·효과크기·불확실성·비교조건을 함께 보고한다.
- 결과 사실과 의미 해석을 구분한다.
- 본문은 표·그림의 핵심 패턴을 설명하고 모든 숫자를 반복하지 않는다.

완료기준:
- 각 RQ에 직접 답하는 결과가 있음
- 표본수·수치·가설판정이 표·그림·본문에서 일치함
- 불리하거나 유의하지 않은 결과도 같은 기준으로 보고함

## 제5장 결론: 결과가 기존 지식과 실무를 어떻게 바꾸는가
권장 흐름:
연구목적 재확인 → RQ별 핵심결과 → 선행연구와 비교 → 작동 메커니즘·조건 → 학술적 기여 → 방법·기술적 기여 → 실무적 시사점 → 한계 → 후속연구 → 최종 결론

작성 원칙:
- 제4장의 숫자를 단순 반복하지 않고 의미를 설명한다.
- 결과가 지지하지 않은 주장과 새로운 인용·분석을 갑자기 추가하지 않는다.
- 기여는 "최초"보다 기존 설명이 어떻게 수정·확장되는지로 쓴다.
- 한계는 사과가 아니라 적용범위와 남은 불확실성을 정확히 정의한다.

## 장·절 연결 문장 틀
- 장 시작: "본 장은 RQ__에 답하기 위해 __를 검토/설계/분석한다."
- 절 시작: "앞 절에서 확인한 __를 바탕으로 본 절은 __를 구체화한다."
- 절 종료: "따라서 __는 제3장의 __ 선택/제4장의 __ 검증 근거가 된다."
- 장 종료: "이상의 결과는 다음 장에서 __의 의미와 기여를 논의하는 기반이 된다."

## 전체 완료기준
- 각 장이 하나의 핵심질문을 담당함
- 같은 내용을 여러 장에서 정의 없이 반복하지 않음
- 제목–초록–서론–RQ–설계–결과–결론의 용어와 범위가 일치함
- 본인의 지도교수가 전 장의 논리와 공개발표 가능 상태를 확인함
