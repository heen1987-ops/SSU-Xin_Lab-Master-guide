# 복사해서 쓰는 논문 검토 서식

필요한 서식만 복사해 연구실의 접근이 제한된 공간에 저장하세요. 이 폴더는 공개 배포용 빈 서식입니다. 대괄호와 빈 행은 입력할 자리이며 실제 기록이나 완료 상태가 아닙니다.

| 서식 | 언제 사용하나 | 작성자 |
|---|---|---|
| [01 검토 요청](01_검토요청.md) | 처음 접수하거나 새 판본 검토를 요청할 때 | 연구자 |
| [02 연구 현황판](02_연구현황판.md) | 여러 연구의 다음 산출물·기한·장애를 볼 때 | 학술총무·연구자 |
| [03 검토와 수정](03_검토와수정.md) | 의견 전달부터 수정·재검토까지 | 검토자·연구자 |
| [04 기여 연결](04_기여연결.md) | 연구 범위를 정하거나 복수 연구를 통합할 때 | 연구자 |
| [05 인수인계](05_인수인계.md) | 담당 변경·장기 중단·재개 시 | 기존·신규 담당자 |
| [06 규정 확인](06_규정확인.md) | 학사 자격·공식 일정·서식을 확인할 때 | 연구자·학술총무 |
| [연구설계·근거 작업지](../docs/assets/research-workbook.md) | RQ·측정·표본·원문 근거를 상세히 작성할 때 | 연구자 |

검토 요청 → 현황판 등록 → 의견·수정·재검토 → 다음 요청으로 연결합니다. 서식의 문서 ID·원고 판본을 유지하고 이전 판본은 보존합니다. 작성 예시는 [학술총무 운영](../handbook/01_학술총무_운영.md)의 가상 피드백을 참고하세요.

자료 없음은 **미확보**, 아직 수행하지 않은 작업은 **미실행**, 읽거나 대조하지 않은 항목은 **미확인**, 적용되지 않는 항목은 **해당 없음과 사유**로 기록합니다.
