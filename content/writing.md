# 인용·표·그림

논문의 문장과 시각 자료는 독자가 **주장과 근거를 확인할 수 있게** 정리합니다. 제출처의 서식을 먼저 확인하고, 원고 전체에서 같은 규칙을 사용하세요.

## 문단을 쓰고 고치는 순서 {#paragraph}

한 문단에는 하나의 중심 생각을 둡니다. 먼저 주장을 적고, 필요한 문헌·자료·예시를 제시한 뒤, 그 근거가 이 연구에서 무엇을 뜻하는지 설명합니다. 모든 문단을 같은 틀로 쓸 필요는 없지만, 인용만 모아 놓거나 결론만 반복하지 않도록 합니다.

수정할 때는 다음을 확인하세요.

- ‘효과적’, ‘우수’, ‘중요’처럼 비교 기준이 없는 표현에 구체적인 근거가 있는가.
- ‘기존 연구’가 어떤 연구를 가리키는지 알 수 있는가.
- 관측한 사실, 연구자의 해석, 향후 제안을 구분했는가.
- 같은 설명이 서론·방법·결론에서 불필요하게 반복되는가.
- 한 문장에 조건과 주장을 너무 많이 넣지 않았는가.

예를 들어 “제안방법은 모든 상황에서 우수했다”보다 “평가한 조건에서 비교방법보다 오차가 작았다. 다만 다른 환경에서의 성능은 확인하지 못했다”가 검증 범위를 분명하게 보여줍니다. 이는 작성 예시이며 실제 연구 결과를 뜻하지 않습니다.

## 원문을 확인하고 인용하기 {#citation}

남의 아이디어·결과·문장을 활용하면 출처를 표시합니다. 다른 표현으로 바꿔 썼더라도 출처가 필요합니다. 직접 인용은 인용임을 구분하고 해당 위치를 적습니다. APA를 사용하는 경우에는 직접 인용·바꿔쓰기·재인용 등의 세부 규칙을 공식 안내에서 확인할 수 있습니다. [APA 본문 인용 안내](https://apastyle.apa.org/style-grammar-guidelines/citations)

인용은 다음 순서로 확인합니다.

1. 제목·저자·연도·출판처·DOI 등 서지정보를 확인합니다.
2. 인용하려는 주장이 실제 원문의 어느 쪽·표·그림에 있는지 읽습니다.
3. 원문의 연구 대상과 조건을 벗어나 해석하지 않았는지 확인합니다.
4. 본문 인용과 참고문헌 항목이 서로 대응하는지 대조합니다.

초록만 읽은 논문으로 세부 방법이나 수치를 단정하지 않습니다. 다른 논문이 소개한 결과를 원저까지 확인하지 못했다면, 직접 읽은 것처럼 쓰지 말고 사용하는 인용 방식의 재인용 규칙을 따릅니다.

인용 양식은 연구방법만으로 결정하지 않습니다. 학위논문 서식과 전공의 작성 기준을 확인한 뒤 저자–연도 방식이나 번호 방식 등을 일관되게 적용합니다. 참고문헌 관리도구를 사용해도 자동 입력된 저자·연도·권호·쪽수·DOI를 직접 확인해야 합니다.

## 표는 비교가 가능하게 만들기 {#tables}

표의 제목은 무엇을 비교하는지 알 수 있게 씁니다. 열·행 이름, 단위, 표본 수 또는 분석 수, 약어, 제외 기준을 필요한 위치에 표시합니다. 본문에서는 표의 모든 숫자를 반복하기보다 연구질문에 답하는 차이를 설명합니다.

| 표의 종류 | 함께 보여줄 정보 |
|---|---|
| 표본·자료 현황 | 수집 수, 제외 수와 이유, 최종 분석 수, 분포 |
| 관계·차이 분석 | 측정 단위, 효과 추정치, 불확실성, 분석 조건 |
| 성능 비교 | 같은 평가자료와 조건, 지표 방향, 반복·변동, 자원 조건 |
| 문헌 비교 | 비교 기준, 각 문헌의 근거, 본 연구와의 관계 |

반올림 자릿수와 결측 표시를 통일합니다. 백분율의 분모가 표마다 다르면 설명을 붙입니다. 평균만으로 중요한 차이가 가려진다면 분포·구간·개별 조건도 보여주세요. [실제 사례의 분모 비교](case-study.md#results)

## 그림은 한 가지 질문에 답하게 만들기 {#figures}

연구모형은 어떤 관계를 검토하는지, 흐름도는 입력과 처리·출력이 무엇인지, 결과 그래프는 어떤 차이가 있는지 보여줘야 합니다. 제목·축·단위·범례를 읽을 수 있게 표시하고, 색만으로 집단을 구분하지 않습니다.

다른 자료의 그림을 그대로 쓰거나 수정했다면 출처와 수정 여부를 밝히고 이용조건을 확인합니다. 화면 캡처를 붙이는 것으로 재현 가능한 방법 설명을 대신하지 않습니다. 표와 그림은 본문에서 먼저 소개하고, 독자가 어디를 봐야 하는지 설명합니다.

## 초록과 제목을 마지막으로 맞추기 {#abstract}

초록에는 문제와 목적, 자료·방법, 핵심 결과, 의미와 적용 범위를 담습니다. 수치가 있다면 본문과 같아야 합니다. 제안이나 계획을 이미 검증한 결과처럼 쓰지 않습니다. 국문·영문 초록에서 대상과 결과, 결론의 강도를 맞춥니다.

제목은 실제 연구 대상과 핵심 문제를 표현합니다. 최종 연구 범위가 바뀌었다면 제목과 초록도 다시 검토하세요. 제목, 표지, 인준서, 제출 정보의 일치 여부와 PDF 변환 뒤 수식·표·그림 상태는 [제출 점검](requirements.md#submission)에서 함께 확인합니다.
