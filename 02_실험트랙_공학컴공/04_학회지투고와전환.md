# 학회지 투고와 학위논문 → 학회지 전환

실험 트랙은 일반적으로 **IEEE 스타일**(본문에 [1], [2] 번호로 인용, 참고문헌은 인용 순서대로 배열)을 쓰지만, 아래 학회마다 이를 변형한 자체 편집양식을 요구하는 경우가 많으니 반드시 해당 학회 스킬로 최종 형식을 확인한다. 인용 스타일 비교는 [08_공공데이터포털과RefWorks.md](../08_공공데이터포털과RefWorks.md) 3절을, 숭실대 학위논문 자체의 참고문헌 규정은 [07_논문서식_필수안내서.md](../07_논문서식_필수안내서.md) 6절을 참고한다.

## 1. 목표 학회지에 맞는 스킬 선택

| 투고 대상 | 스킬 |
|---|---|
| 한국HCI학회논문지 | `ssu-hci` |
| 한국통신학회논문지 | `ssu-kics` |
| 한국정보통신학회논문지 | `ssu-kiice` |
| 정보보호학회논문지 | `ssu-kiisc` |
| 정보과학회논문지 | `ssu-kiise` |
| 한국정보기술학회논문지 | `ssu-kiit` |
| 정보처리학회논문지 | `ssu-kips` |
| 한국컴퓨터정보학회논문지 | `ssu-ksci` |
| 인터넷정보학회논문지 | `ssu-ksii` |
| SCI/SCIE 국제 저널(IEEE Access 등), JCR/SJR 사분위 확인 | `ssu-sci` |

목표 학회지가 아직 정해지지 않았으면 `cs-paper-data-design`으로 초안을 먼저 진행하고, 정해지면 위 표의 스킬로 넘어갑니다. 학회 이름을 짐작해서 미리 확정하지 않습니다.

## 2. 학위논문 → 학회지 전환 시 반드시 대조할 것

두 산출물(학위논문 초고와 학회지 원고) 사이에 내용이 자동으로 대조되는 도구는 없습니다. 아래 세 가지를 **직접 수기로 대조**해야 합니다.

1. 학회지 원고의 연구질문 문구가 학위논문 설계 파일의 연구질문과 같은가.
2. 학회지 원고의 각 주장이 인용하는 근거가 학위논문 쪽에서 실제로 확인·검수한 근거와 같은 대상을 가리키는가(이름만 비슷한 다른 근거로 바뀌지 않았는가).
3. 수치·데이터셋 출처·버전이 두 산출물에서 다르게 적혀 있지 않은가.

불일치를 발견하면 어느 쪽이 최신인지 먼저 확인하고, 임의로 하나를 골라 넘어가지 않습니다.

## 3. 학위논문과 학회지 원고의 차이

| 요소 | 학위논문 | 학회지 논문 |
|---|---|---|
| 중심 과제 | 연구과정·이론적 토대·설계·분석을 추적 가능하게 설명 | 핵심 연구질문과 기여를 중심으로 집중 |
| 관련 연구 | 충분히 설명 | 가설·기여에 직접 필요한 것만 선별 |
| 실험/방법 | 재현 가능하도록 상세히 | 핵심만 남기고 부록/보충자료 활용 |
| 전환 시 주의 | 원 연구 구조 보존 | 단순 축약이 아니라 메시지 중심 재구성 |

## 4. 여러 학회지를 동시에 검토할 때

각 학회지 스킬을 순서대로 개별 호출합니다. 한 학회지의 규정 점검 결과를 다른 학회지에 그대로 적용하지 않습니다 — 투고 규정은 학회마다 다릅니다.

## 5. 제출 전 확인

- 목표 학회지의 최신 투고 규정(형식, 분량, 인용 스타일)을 공식 홈페이지에서 다시 확인했는가.
- 이중 투고·자기표절 관련 규정을 확인했는가(같은 데이터로 학위논문과 학회지 논문을 냈다면 그 관계를 명시).
- AI 사용 공개가 필요한 학회인지 확인했는가.
