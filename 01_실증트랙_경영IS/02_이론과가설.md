# 이론 선택과 가설 도출

## 1. 변수의 역할은 관계마다 다시 정한다

독립·종속·매개·조절 변수는 그 개념 자체의 고정된 성질이 아니라 **이번 연구의 관계**에서 정해집니다. 같은 구성개념이 어떤 모형에서는 결과변수, 다른 모형에서는 설명변수일 수 있습니다.

| 역할 | 정의할 내용 |
|---|---|
| 독립/설명 변수 | 이번 관계에서 설명에 사용하는 변수와 선택 근거 |
| 종속/결과 변수 | 이번 질문이 설명하려는 결과와 측정 시점 |
| 매개 변수 | 가정한 중간 메커니즘과 간접효과의 대상 |
| 조절 변수 | 관계가 달라지는 조건과 상호작용·차이 검정의 대상 |

## 2. 자주 쓰이는 이론 후보

아래 표는 "이 이론이 우월하다"는 순위가 아니라 **문제 유형별 출발점**입니다. 내 주제가 표에 없으면 다른 이론을 조사하고, TAM/UTAUT에 억지로 맞추지 않습니다.

| 설명하려는 문제 | 이론 후보 | 먼저 점검할 사항 |
|---|---|---|
| 행동에 대한 태도·주변 기대와 의도 | TRA, TPB | 행동 통제·자원 제약을 포함해야 하는가 |
| 기술의 유용성·사용 노력과 수용 | TAM, TAM2 | 업무 사용 맥락, 초기/반복 사용, 사회적 영향의 역할 |
| 성과·노력·사회적 영향·촉진조건 | UTAUT | 실제 사용과 의도의 구분, 조절변수를 넣는 이론적 이유 |
| 혁신의 상대적 이점·적합성·관찰 가능성 | IDT | 기존 대안과 비교하는 혁신 속성이 핵심인가 |
| 자기효능감·기대 결과·불안 | SCT 등 | 개인 능력·동기·환경의 역할이 질문과 맞는가 |
| 품질·만족·지속사용과 신뢰 | D&M IS Success, 신뢰 이론 | 신뢰 대상과 경로 방향, 최초 수용과 지속사용의 차이 |
| 고객관계 편익·가치·품질·몰입 | 관계마케팅 문헌 | B2B/B2C, 개념 중복, 직접효과와 매개효과 |

비슷해 보이는 개념(유용성·성과기대·상대적 이점 등)을 무조건 합치지 마세요. 정의, 이론에서의 역할, 실제 문항과 맥락을 비교한 뒤 하나를 선택합니다.

## 3. 선행연구를 모형의 근거로 연결하기

모형의 화살표 하나하나에 실제 문헌을 연결합니다. 문헌 수를 늘리는 것보다 **경로의 논리**가 있는지가 중요합니다.

| 문헌(원문 확인 여부) | 맥락·표본·시점 | 이론·개념 | 측정·방법 | 핵심 결과·불확실성 | 한계·반대 증거 | 내 연구에 연결할 경로 |
|---|---|---|---|---|---|---|
| | | | | | | |

선행연구의 결론, 저자의 해석, 내가 확장하려는 아이디어를 분리해서 적습니다.

## 4. 가설 하나하나의 논증 구조

각 가설은 다음 다섯 가지가 갖춰져야 합니다: **개념 정의 → 작동 메커니즘 → 선행 증거/반례 → 현재 맥락에의 적용 → 방향·조건**.

| H ID | 경로·유형 | 이론적 메커니즘(왜 X가 Y와 연결되는가) | 근거 문헌·위치 | 대안 설명·경계조건 | 검정에 필요한 자료 |
|---|---|---|---|---|---|
| H1 | X → Y, 정적 관계 | | | 역방향·공통원인 가능성 등 | X·Y 측정, 설계·분석 계획 |

- **방향가설**: 왜 정(+)/부(−) 방향을 예상하는지 설명합니다. 근거가 부족하면 무방향 가설이나 탐색적 연구질문으로 남깁니다.
- **매개가설**: X→M, M→Y 각각의 논리를 따로 설명하고 간접효과의 대상을 명시합니다.
- **조절가설**: 어떤 조건(Z)에서 X-Y 관계의 방향·크기가 어떻게 달라지는지 씁니다.
- **통제변수**: "다들 넣으니까"가 아니라 연구질문·인과구조에 근거해 포함합니다.

모형 그림의 모든 화살표는 H ID와 1:1로 대응해야 합니다. 연구 범위 밖의 관계는 검정 경로와 명확히 구분합니다.

## 5. 데이터를 보기 전에 고정할 것

자료를 수집·분석하기 전에 주요 가설, 주/부 결과, 제외 기준, 분석 방법을 미리 문서로 남깁니다. 이후 바뀐 부분이 있으면 이유·시점·영향을 기록하고, 확인적 분석과 탐색적 분석을 구분합니다.

**흔한 유혹**: 가설이 지지되지 않으면 그 변수를 슬쩍 빼서 "채택된 가설 수"를 늘리고 싶어집니다. 그러지 말고 원래 모형을 유지한 채 왜 예상과 다른 결과가 나왔는지 논의합니다. 결과를 본 뒤 이론을 처음부터 그랬던 것처럼 다시 쓰지 않습니다.
