# 집필과 심사 대응

## 1. 학위논문과 학술지 논문은 강조점이 다르다

| 요소 | 학위논문 | 학술지 논문 |
|---|---|---|
| 중심 과제 | 연구과정·이론적 토대·설계·분석을 추적 가능하게 설명 | 핵심 연구질문과 기여를 중심으로 논증을 집중 |
| 이론적 배경 | 정의·발전·선행연구 비교를 충분히 설명 | 가설과 기여에 직접 필요한 이론만 선별 |
| 방법·분석 | 조작적 정의, 측정, 검증 절차를 상세히 연결 | 재현에 필요한 핵심만 남기고 나머지는 부록으로 |
| 전환 시 주의 | 기존 연구의 전체 구조를 보존 | 단순 축약이 아니라 질문·메시지·기여에 맞춰 재구성 |

이 표는 특정 사례에서 정리한 것이며 모든 대학·학술지의 고정 규칙이 아닙니다. 실제 규정은 학과·학술지의 최신 공지를 따릅니다.

## 2. 장별로 채워야 할 논증

**제목** — 핵심 개념·관계·연구맥락을 표현합니다. 분석으로 확인하지 않은 매개·인과·일반화를 제목에 확정적으로 넣지 않습니다.

**서론** — `현상의 중요성 → 기존 연구의 설명 → 남은 문제 → 연구질문·목적 → 접근·기여` 순서로 씁니다. 문단마다 `핵심 주장 + 근거 + 이 연구에의 연결`이 있는지 확인하고, 근거가 없으면 지어낸 인용 대신 `[원문 확인 필요]`를 남깁니다.

**이론적 배경·가설** — 개념 정의와 구분, 이론의 역할, 선행연구의 일치/불일치, 현재 맥락에의 적용을 설명합니다. 가설표에는 있는데 본문에서 논리적으로 도출되지 않은 경로가 없는지 확인합니다.

**방법** — 독자가 실제 수행 과정을 따라갈 수 있도록 대상·표집·기간·동의/윤리 정보·문항 출처와 수정·최종 표본 흐름·분석 방법을 씁니다. 계획한 일을 이미 완료한 사실처럼 과거형으로 쓰지 않습니다.

**결과** — 연구질문/가설 순서로 실제 추정치와 불확실성, 판정을 보고합니다. 표를 그대로 반복하지 말고 중요한 관계와 예외를 설명합니다. **지지되지 않은 가설도 빠짐없이 보고합니다.**

**논의·시사점·한계** — 각 결과를 `관찰 결과 → 이론과의 일치/차이 → 가능한 설명과 대안 → 기여 → 적용 조건`으로 연결합니다. 가능한 설명을 새로운 분석 결과인 것처럼 쓰지 않습니다. 한계는 `설계/표본/측정의 제약 → 어떤 해석을 제한하는지 → 이를 다룰 후속 연구`로 구체적으로 씁니다.

### 장별 완료 기준 (다음 장 연결 여부로 판단)

각 장은 "얼마나 썼는가"보다 "다음 장과 어떻게 연결되는가"를 기준으로 완료 여부를 판단합니다.

- **제3장(연구설계) 완료 기준**: 다른 연구자가 같은 연구를 수행할 수 있고, 지도교수가 본 연구 착수를 승인함.
- **제4장(연구결과) 완료 기준**: 모든 연구질문에 결과가 대응하고 수치·표·본문이 일치함.
- **제5장(결론) 완료 기준**: 모든 결론이 제4장의 근거로 추적되고 연구목적에 답함.
- **제2장(이론적 배경) 완료 기준**: "왜 이 질문과 방법인가?"에 대한 답이 제2장만으로 설명됨.
- **제1장(서론) 완료 기준**: 처음 읽는 사람이 필요성, 대상, 방법, 기여를 빠르게 이해함.

**제3장 작성 팁**: 예상되는 표·그림의 빈 양식을 먼저 만들어 두고, 그 양식을 채우는 데 필요한 데이터가 무엇인지 역산해서 수집·분석 계획에 반영합니다.

## 3. 초록 쓰는 순서

`배경·중요성 → 공백 → 목적·이론 → 방법·표본 → 핵심 결과 → 의미·확장`

아직 데이터가 없다면 "연구계획서용 초록"임을 명시하고 목적·계획된 방법·기대 기여까지만 씁니다. 결과형 초록을 요청받아도 결과를 지어내지 않습니다.

## 4. 가설 판정 용어

기본적으로 "지지/미지지/판정 불가"를 쓰고 추정치·CI·p·설계 조건을 함께 적습니다. 소속 기관이 "채택/기각" 표기를 요구하면 그에 따르되, 연구가설과 통계적 귀무가설을 혼동하지 않습니다. 비유의 결과를 "효과가 없다"로 바꿔 쓰지 않습니다.

## 5. 심사 의견 대응표

| 의견 ID | 지적 요지 | 필요한 근거·확인 | 조치·수정 문안 | 위치·버전 | 답변(수용/부분수용/근거 있는 이견) | 상태 |
|---|---|---|---|---|---|---|

의견을 무조건 수용하지 않습니다. 연구목적·자료·결과와 충돌하면 반영 범위와 이유를 설명합니다. 실제로 하지 않은 추가 분석을 "확인했다"고 답변하지 않습니다.

### 공개발표 이후 처리 흐름

공개발표 직후 처리 순서는 다음 5단계입니다: ① 의견 원문 기록 → ② 지도교수 협의 → ③ 추가분석·수정 → ④ 반영표 작성 → ⑤ 종심·제출.

발표 자료 자체와 분리해서 관리할 항목(Appendix): 변수 정의, 전체 설문문항, 세부 통계표, 추가 실험결과, Hyperparameter, Ablation, 민감도 분석과 예상질문 근거자료는 본 발표 자료와 분리해 둡니다.

## 6. 제출 전 최종 점검표

- 제목·연구질문·가설·측정·결론이 같은 대상을 설명하는가.
- 개념 정의·번역·기호·H ID·문항 ID가 처음부터 끝까지 일관되는가.
- 원고의 모든 수치가 실제 출력·표본·버전과 연결되는가.
- 원문을 확인한 인용과 재인용을 구별했는가.
- 부정적·비유의·예상 밖 결과와 한계를 숨기지 않았는가.
- 직접효과·간접효과·조절효과, 집단 차이를 구분했는가.
- 초록의 N·핵심 결과·결론이 본문과 일치하는가.
- 참고문헌 형식(저자·연도·제목·권호·DOI)이 APA7 등 요구 형식과 맞는가. 실증 트랙은 일반적으로 **APA7**(저자-연도 인용)을 표준으로 쓰지만, 숭실대 학위논문 자체의 참고문헌 규정(저자 4인 이상도 모두 표기 등)이 APA7과 다를 수 있으니 [07_논문서식_필수안내서.md](../07_논문서식_필수안내서.md) 6절과 대조한다. RefWorks·Zotero 활용법은 [08_공공데이터포털과RefWorks.md](../08_공공데이터포털과RefWorks.md)를 참고한다.
- AI 도구의 작성 보조와 연구자 본인의 실제 수행을 혼동하지 않았는가. 제출처가 요구하는 AI 사용 공개 규정을 확인했는가.
- 목차·표목차·그림목차의 번호와 쪽수가 일치하는가.
- 표·그림의 제목, 단위, 출처, 주석이 통일되어 있는가.
- 국문·영문 제목, 초록, 핵심어, 본문 용어가 일치하는가.
