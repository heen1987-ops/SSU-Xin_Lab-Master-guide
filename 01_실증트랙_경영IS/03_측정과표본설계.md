# 측정(설문 문항)과 표본 설계

## 1. 구성개념을 문항으로 연결하는 표

문항을 쓰기 전에 아래 표부터 채웁니다. 기존 검증된 척도를 쓰더라도 지금 언어·맥락에서 타당한지는 별도로 확인해야 하며, 과거 연구의 신뢰도(α)를 지금 자료의 신뢰도로 그대로 가져다 쓰지 않습니다.

| 개념 ID·정의 | 역할(독립/종속/매개/조절) | 문항 ID·측정내용 | 원척도·원문 위치 | 번역·수정 이유 | 응답척도·역문항 여부 | 예비조사 결과 |
|---|---|---|---|---|---|---|
| | | | | | | |

문항을 쓰기 전, 그 개념과 지표의 관계가 **반영형(reflective)**인지 **형성형(formative)**인지 이론적으로 먼저 판단합니다. 신뢰도·AVE 중심의 반영형 검사를 형성형 지표에 그대로 적용하지 않습니다.

### 설문 문항 점검 목록

- 응답 대상·기간·기준 서비스를 명확히 고정했는가(여러 서비스를 떠올릴 수 있는 질문이면 기준을 안내).
- 이중질문, 유도 표현, 모호한 용어, 경험하지 않은 행동을 경험한 것처럼 묻는 문항이 없는가.
- 전문가 검토와 실제 응답 대상자의 이해도 확인(예비조사)을 실제로 계획했는가. "3~4명에게 물어봤다"가 모든 연구에 충분한 예비조사는 아닙니다.
- 번역·검토·예비조사를 **계획했다**와 **실제로 했다**를 구분해서 기록했는가.
- 문항을 바꾸거나 뺐다면 원본, 이유, 시점, 개념 범위에 미친 영향을 남겼는가. 신뢰도 숫자를 높이려고 문항을 기계적으로 늘리거나 빼지 않습니다.

## 2. 표본과 수집 계획

다음 순서로 적어봅니다.

`목표 모집단 → 접근 가능한 모집틀 → 모집·표집 방식 → 참여/제외 기준 → 목표 N의 근거 → 수집 기간·절차 → 분석별 최종 N`

- 모집틀의 범위와 표집 방식이 대표성을 어떻게 제한하는지 적습니다.
- **편의표집**을 확률표집·무작위표집이라고 부르지 않습니다.
- 학교·지점·조직에 묶인 응답, 반복측정, 동일 응답자의 복수 자료가 있으면 독립성 문제를 검토합니다.

### 표본 수에 대한 흔한 오해

"SEM이면 200명은 있어야 한다", "선배 논문이 324명이었으니 나도 그 정도면 된다" 같은 말은 **필수/충분 기준이 아닙니다.** 표본 수는 핵심 효과 크기, 모형 복잡성, 검정력(또는 정밀도), 군집 구조, 예상 결측률, 집단별 분석 여부에 맞춰 계획합니다. 계산 근거 없이 "산정 완료"라고 쓰지 않습니다.

### 수집·정제 흐름표

| 단계 | 실제 N | 변경/제외 이유 | 근거·시점 | 파일·분석 버전 |
|---|---|---|---|---|
| 모집/배포 | | 모집과 응답을 구분 | | 원본 |
| 응답/회수 | | 중복·불완전 등 | 사전 기준과 사후 판단 구분 | 원본 보존 |
| 분석 포함 | | 결측 처리·모형별 차이 | 처리 로그 | 가공본 |

동의·윤리심의가 필요한지는 소속 기관과 연구 유형의 실제 요건을 확인하세요. 승인번호를 추정해서 쓰지 않습니다.

## 3. 신뢰도·타당도, 참고치일 뿐 절대기준이 아니다

강의나 논문에서 흔히 보는 "α ≥ 0.7", "AVE ≥ 0.5" 같은 숫자는 **해당 자료·모형에서의 참고값**이지, 이 숫자만 넘으면 무조건 합격이라는 자동 판정 기준이 아닙니다. 실제로 적용하려면 원출처·모형·연구단계·척도 조건을 함께 확인하고, 원문을 못 찾았으면 "관행적 참고값, 적용 미검증"이라고 표시합니다.

| 점검 대상 | 흔히 보는 기준 | 초심자가 주의할 점 |
|---|---|---|
| 신뢰성(α) | 0.6~0.7 이상 | α 하나로 단일차원성·타당성·모든 신뢰성이 확보됐다고 확정하지 않는다 |
| 수렴타당성 | 적재값, AVE·CR | 모형과 지표 정의·산출식을 확인하고 계산한다 |
| 판별타당성 | Fornell-Larcker, HTMT | 기준 통과만으로 개념 중복이 없다고 단정하지 않는다 |
| 동일방법편의 | 단일요인 검사 등 | 단일 진단 통과만으로 편의가 완전히 제거됐다고 쓰지 않는다 설계 단계 예방은 [09번 지침](../12_단계별_지침_라이브러리/09_설문측정척도품질.md) |
