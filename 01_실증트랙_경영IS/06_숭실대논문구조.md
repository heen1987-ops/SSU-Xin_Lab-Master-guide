# 숭실대 논문 구조 참고

**주의: 아래는 과거 실제 학위논문 관찰과 편집 제안이며, 대학 전체의 공식 규정이나 지도교수의 모범논문 지정 목록이 아닙니다. 제출 학기의 공식 공지와 학과·지도교수 요구를 반드시 다시 확인하세요.**

## 세 가지 근거를 구별해서 읽기

| 근거 지위 | 내용 | 적용 방법 |
|---|---|---|
| 공식 작성 안내 | 겉표지·앞부분·본문·참고문헌·부록의 순서, 페이지·제목 체계 | 제출 학기의 대학원 공지·현행 규정·학과 요구를 확인 |
| 실제 논문 관찰 | 설문/SEM 기반 논문들의 5장 구성 사례 | 연구 목적·방법이 맞는 장의 "기능"을 참고 |
| 편집 제안 | 연구질문 → 가설/평가기준 → 방법 → 결과표 → 논의 → 기여의 대응 | 내 연구에 맞게 채우고 근거 없는 칸은 표시 |

대학원 공식 안내와 학칙에서 "본문을 반드시 5장으로 구성하라"는 규정은 확인되지 않았습니다. 다만 학과·지도교수가 별도로 요구할 수 있습니다.

공식 안내상 논문 전체 구비 순서는: 겉표지 → 백지간지 → 표제지 → 속표지 → 인준서 → 감사의 글(필요시) → 논문목차 → 표·그림 목차 → 초록 → 본문 → 참고문헌 → 부록·색인 순입니다. 국문 논문은 국문·외국어 초록 순으로 둡니다. 이 순서는 2026년(20.5기) 석사학위청구논문 심사 결과보고서 3건이 "학칙시행세칙(대학원) 제48조"를 그대로 인용해 확인하고 있고([../05_최근논문벤치마킹.md](../05_최근논문벤치마킹.md) 참고), `rule.ssu.ac.kr`에서 **제48조(학위논문의 형식) 원문을 직접 열람해 위 순서와 정확히 일치함을 재확인**했습니다(2026-09-22). 다만 이 조문은 2025.11.28에 개정되어 판형·규격을 나열하던 옛 2~5호가 삭제되고 "겉표지 인쇄방식은 별지 제2호 서식에 따름"처럼 별지 서식 참조로 단순화되었으니, 색상·인쇄 방식 등 세부 규격은 이 문서가 아니라 대학원이 배포하는 최신 별지 서식을 확인하세요.

## 설문·SEM 논문의 기본 초안 (편집 제안)

분량 비율·변수 수·표본 수를 정하는 규정이 아니라, 장별로 무엇을 답해야 하고 다음 장에 무엇을 넘겨야 하는지를 정리한 표입니다. 방법이 길어지면 모형·가설과 연구방법을 별도 장으로 나눌 수 있습니다.

| 장 | 반드시 답할 내용 | 다음 장으로 넘길 산출물 |
|---|---|---|
| 1. 서론 | 어떤 현상이 문제이며 선행연구로 해결되지 않은 질문은 무엇인가. 연구 범위·접근·기여는 무엇인가 | 연구질문 ID, 분석단위·대상, 연구 범위 |
| 2. 이론적 배경 | 개념의 경계와 선택한 이론은 무엇이며, 기존 결과는 어디서 일치·충돌하는가 | 개념 정의, 경로별 문헌 근거와 남는 설명 문제 |
| 3. 연구모형 및 연구설계 | 어떤 관계를 왜 가정하며 무엇으로 측정·검정할 것인가 | 모형·H ID, 조작적 정의·문항 ID·원출처, 표집·윤리·분석계획 |
| 4. 실증분석 및 논의 | 어떤 자료로 무엇을 확인했으며 결과는 질문·이론에 어떤 답을 주는가 | 표본 흐름, 측정 평가, 가설별 결과, 결과별 해석 |
| 5. 결론 | 이 연구가 추가한 설명은 무엇이며 어디까지 적용할 수 있는가 | 학술·실무 기여, 제약→해석 제한→후속 설계 |

데이터가 아직 없다면 4·5장은 빈 결과표, 논의를 위한 질문, 기여 후보까지만 만들어 둡니다.

### 제2장과 제3장을 한 세트로 점검

제2장은 지식을 나열하는 장이 아니라 제3장의 선택을 설명하는 근거이고, 제3장은 그 논리를 검증 가능한 절차로 바꾸는 장입니다. 아래 대응표로 둘을 짝지어 점검하세요.

| 제2장 근거 | 제3장 구현 | 검토 질문 |
|---|---|---|
| 핵심 개념 정의 | 조작적 정의·측정문항 | 같은 의미로 측정하는가? |
| 이론·선행모형 | 연구모형·가설 | 모든 경로에 근거가 있는가? |
| 기존 연구의 한계 | 대상·맥락·방법의 차별성 | 설계가 한계를 보완하는가? |
| 연구 Gap | 연구질문·검증항목 | 결과로 Gap에 답할 수 있는가? |

**장간 연결 체크리스트**
- 제3장의 모든 핵심 개념이 제2장에 정의되어 있음
- 각 가설·연구질문에 직접 연결되는 선행연구가 있음
- 측정도구·척도의 원출처와 적용 근거를 확인함
- 제2장의 연구 Gap이 제3장의 설계로 해결됨

**최신 사례(2026, 20.5기):** 김승연, "생성형 AI 기반 축제큐레이터 서비스의 사용의도에 영향을 미치는 요인에 관한 연구", IT정책경영학과 석사, 신용태 지도, 2026.06. 공개발표 자료(목차·참고문헌 48건)로 확인한 결과이며 본문 전체는 읽지 않았다. 목차는 위 5장 구성과 정확히 일치하고, 이론적 기반은 [이론과가설](02_이론과가설.md)의 후보표(TAM, UTAUT, D&M IS Success, 신뢰 모형)와 겹친다. 상세는 [../05_최근논문벤치마킹.md](../05_최근논문벤치마킹.md) 참고.

## 인준서·쪽번호 등 형식 요건

dCollection 온라인 제출 매뉴얼(26-1학기 기준)에 따르면 인준서의 심사위원 수는 **석사 3명, 박사 5명**이며 도장 또는 서명이 필수입니다. 쪽번호는 `겉표지~감사의 글: 없음 → 목차~영문초록: 로마숫자 i부터 → 본문~부록: 아라비아숫자 1부터` 순으로 매깁니다. 페이지 순서가 규정과 다르면 제출이 반송됩니다. 상세 체크리스트는 [../06_논문제출절차와체크리스트.md](../06_논문제출절차와체크리스트.md)에 정리했습니다.

아래는 전체 80쪽 안팎을 가정한 분량 배분 예시입니다. 학교의 공식 분량 기준이 아니며, 연구질문·방법·결과를 설명하는 데 필요한 분량을 지도교수와 정합니다.

## 다른 유형의 연구라면

설문·SEM이 아니라 AHP(의사결정 기준의 중요도), DEA(효율성 평가), 기술 실험(알고리즘·시스템) 연구라면 5장 구조를 그대로 쓰지 않습니다. 연구가 답하려는 질문에 따라 아래처럼 장의 기능이 달라집니다.

| 연구가 답할 질문 | 구성의 기능 |
|---|---|
| 의사결정 기준의 상대적 중요도는 무엇인가 (AHP) | 문제 → 기준의 근거 → 요인·계층·조사 설계 → 일관성·가중치·우선순위 → 함의 |
| 비교 대상의 투입·산출 대비 효율성은 어떠한가 (DEA) | 문제·개념 → 평가모형·대상·투입/산출 정의 → 모형별 효율성·종합 → 함의 |
| 제안한 기술이 비교 기준보다 어떤 조건에서 개선되는가 (기술 실험) | 문제 → 관련 연구 → 알고리즘 → 시스템 설계 → 실험·비교 → 결론 (→ [실험 트랙](../02_실험트랙_공학컴공/) 참고) |

설문이라는 이유만으로 SEM을 확정하거나, AHP·DEA·기술 실험에 잠재변수 가설·신뢰도 검사를 억지로 넣지 않습니다.

## 주의: 선배 논문을 참고 사례로 볼 때

- 선배 논문에 특정 통계 검사(정규성 검정, 동일방법편의 검사 등)가 있다는 이유만으로 내 논문에도 무조건 같은 검사를 넣지 않습니다. 검사마다 내 연구질문·가정에 맞는 역할이 있어야 합니다.
- "단일요인 설명비율이 낮으니 동일방법편의 문제 없음"이라는 절 제목만 보고 그 논리를 그대로 복사하지 않습니다.
- 경로 크기와 통계적 유의성, 한 집단에서의 유의성과 집단 간 차이, 표본 내 설명력과 표본 밖 예측력을 구분합니다. 선배 논문의 해석을 새로운 방법론적 근거로 삼지 않습니다.
- 특정 논문의 특정 문구·구성을 그대로 베끼지 말고, **구조적 아이디어**(장을 어떻게 나눴는지, 표를 어떻게 연결했는지)만 참고합니다.
