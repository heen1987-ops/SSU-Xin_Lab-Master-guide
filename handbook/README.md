## 읽는 순서

연구자는 **검토 요청서 → 이번 단계의 연구 안내 → 근거와 원고 → 수정 답변표** 순서로 준비합니다. 학술총무는 **접수 → 범위 확인 → 내용 검토 → 지도교수에게 확인할 쟁점 정리 → 재검토 → 현황 갱신** 순서로 운영합니다.

학위과정, 연구방법, 산출형식은 각각 기록합니다. 예를 들어 박사과정 연구자가 실증 방법으로 학술지 원고를 작성할 수 있습니다. 학위과정만으로 장 수·SEM·특정 학술지·표본 수를 정하지 않습니다.
