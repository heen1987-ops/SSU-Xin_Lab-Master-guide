# 석사·박사 논문을 함께 검토하는 기준

같은 기준으로 연구의 정직성·논리·근거를 확인하면서, 각 연구에서 합의한 기여와 독립성의 범위를 다르게 질문합니다. 아래 비교는 상담을 위한 기준안이며 학교의 공식 합격 기준이 아닙니다. 실제 학위·학과의 기대와 지도교수의 요구를 먼저 확인합니다.

## 1. 공통 기준과 상담의 초점

| 검토 축 | 모든 연구에서 확인 | 석사 논문 상담의 초점 | 박사 논문 상담에서 더 깊게 물을 것 |
|---|---|---|---|
| 질문과 범위 | 대상·조건·답할 질문이 분명한가 | 제한된 범위 안에서 질문 하나를 끝까지 검증할 수 있는가 | 핵심 질문이 관련 분야의 설명·방법·지식에 어떤 새 이해를 더하는가 |
| 선행연구 | 실제 읽은 근거와 비교축이 있는가 | 관련 연구를 이해하고 연구 선택의 이유를 설명하는가 | 가장 가까운 연구와 강한 대안을 대조해 독창성의 경계를 방어하는가 |
| 방법 선택 | 질문·자료·추론 목표가 맞는가 | 선택한 방법의 가정과 한계를 이해하고 적용하는가 | 방법·이론의 선택을 독립적으로 정당화하고 대안 설명에 대응하는가 |
| 결과와 검증 | 실제 자료와 불확실성·실패를 보고하는가 | 합의한 범위에서 결과를 신뢰할 근거가 있는가 | 중심 주장에 필요한 강건성·경계조건·반례 검증이 충분한가 |
| 기여 | 기존 지식과 달라지는 내용을 근거로 설명하는가 | 재현·적용·확장 등 기여 성격과 한계를 분명히 하는가 | 개별 결과가 독립적이고 응집된 학술적 기여로 연결되는가 |
| 설명과 책임 | 본인이 판단·수정·결과를 설명하는가 | 연구 과정을 이해하고 자기 논문의 결정을 설명하는가 | 반론에 따라 주장을 조정하고 전체 연구의 선택과 한계를 방어하는가 |

석사에 새로운 기여가 필요 없다는 뜻도, 박사에 반드시 복수 연구·신규 알고리즘·특정 저널이 필요하다는 뜻도 아닙니다. 기여는 이론·방법·자료·측정·경계조건·재현 검증 등으로 나타날 수 있으며 실제 연구의 근거로 판단합니다.

## 2. 범위를 합의하는 방법

연구자와 지도교수의 상담을 위해 **이번 논문의 핵심 기여 / 필요한 근거 / 제외할 주장 / 완료 판단 자료 / 일정 제약**을 한 묶음으로 정리합니다. 학술총무는 빠진 연결을 질문하고 실제 결정 내용을 기록합니다.

“박사니까 실험을 더 하자” 대신 “현재 결과만으로는 환경 변화에 관한 주장을 지지할 수 없다. 해당 조건을 검증하거나 주장을 현재 환경으로 줄이자”처럼 구체화합니다. 추가 분석이 필요한 이유와 종료 기준도 함께 정합니다.

장 수·가설 수·문헌 수·분량·표본 수는 학위명만으로 고정하지 않습니다. 한 장을 늘리거나 데이터를 더 모으는 일이 기여의 부족을 자동 해결하지 않습니다.

## 3. 여러 연구를 하나의 논문으로 묶을 때

박사논문 등에서 복수 연구를 수행한다면 [기여 연결표](../templates/04_기여연결.md)로 다음을 설명합니다. 단일 연구에도 같은 표를 사용할 수 있습니다.

1. 모든 연구를 묶는 중심 질문과 논문 전체의 기여.
2. 연구 A·B가 각각 답하는 하위 질문, 자료·분석단위·방법.
3. 연구 간 연결: 앞 연구의 한계를 보완하는지, 다른 조건을 검증하는지, 다른 종류의 증거를 제공하는지.
4. 자료·표본·코드·문헌의 재사용 범위와 독립성. 같은 자료를 여러 독립 증거로 세지 않는다.
5. 각 연구의 실제 결과·미실행 항목·서로 충돌하는 결과.
6. 개별 결과가 허용하는 전체 결론과 아직 연결할 수 없는 주장.

기술 성능이 좋아졌다는 결과만으로 사용자 신뢰나 조직 성과 향상을 결론내리지 않습니다. 별도 사용자 연구가 있더라도 대상·조건이 다르면 연결 범위와 한계를 설명합니다.

## 4. 단계별 면담 질문

| 시점 | 공통 질문 | 기여가 복잡하거나 범위가 넓을 때 추가 질문 |
|---|---|---|
| 주제·계획 | 어떤 미해결 질문에 어떤 자료로 답할 것인가 | 가장 가까운 연구가 이미 답한 부분과 남은 부분은 무엇인가 |
| 설계 확정 전 | 결과가 기대와 다르면 어떤 결론을 낼 것인가 | 경쟁 설명·반례·경계조건을 구별할 설계인가 |
| 중간 결과 | 관측과 해석이 어디서 갈리는가 | 연구별 결과가 서로 다른 방향이면 전체 주장은 어떻게 변하는가 |
| 전체 초안 | 각 핵심 주장에 직접 근거가 있는가 | 여러 장이 한 기여를 논증하는가, 독립 보고서의 나열인가 |
| 심사 준비 | 가장 약한 주장과 그 한계는 무엇인가 | 강한 반론에 대한 근거·수정 선택지를 스스로 설명하는가 |

## 5. 연구 평가와 행정 자격을 분리하기

논문의 학술적 준비도와 학점·종합시험·연구실적·심사 절차 충족 여부는 별도로 확인합니다. 연구실 내부 검토가 잘 끝나도 제출 자격이 자동 충족되지는 않습니다. 게재 실적이 있어도 학위논문 전체의 기여와 논증은 검토해야 합니다.

[학사·제출 요건](../04_석사와_박사의_차이.md)과 [규정 확인표](../templates/06_규정확인.md)에 입학연도·과정·계열·목표 제출학기를 기록하세요.
