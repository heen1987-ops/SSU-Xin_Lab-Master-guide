연구방법

실험 · 실증 · 혼합 · 미정

질문, 분석단위와 필요한 증거를 보고 선택합니다. 실증을 설문·SEM으로 자동 한정하지 않습니다.

산출형식

학위논문 · 학술지 · 미정

장 구성과 제출 규정은 산출물의 조건입니다. 연구방법을 선택했다고 형식이나 필수 장 수가 정해지지 않습니다.

현재 근거

확보한 자료 · 읽은 범위 · 실행 상태

가정·미확보·미실행·검토 완료를 구분합니다. 자료가 적으면 가능한 초안과 다음 확인을 작성합니다.

혼합연구: 연구별 RQ·자료·분석단위·방법·지표·실행상태를 분리한 뒤 전체 기여와 연결합니다. 기술 성능 개선이 사용자 효과나 인과성의 근거를 대신하지 않습니다.

실증 상세 안내실험 상세 안내학사·제출 요건

공백에서 연구질문·기여·반증 조건까지

누가 어떤 조건에서 무엇을 하지 못하는지와, 제안할 기법을 구분합니다. 선행연구의 확인된 한계로 질문을 좁힙니다.

  1. 실제 문제·대상·분석단위·조건을 한 문단으로 씁니다.
  2. 문헌별 해결 범위와 한계의 페이지를 기록하고 원저자의 보고와 내 해석을 분리합니다.
  3. 공백–RQ–후보 기여에 강한 비교 접근·대안 설명·검증 방법을 연결합니다.
  4. 무엇이 나오면 주장을 축소하거나 재검토할지 반증 조건을 적습니다.

근거가 부족하면: 공백 가설과 다음 원문 확인을 남깁니다. 검색 실패·초록의 정보 부족으로 ‘최초 연구’를 확정하지 않습니다.

RQ ID → 공백과 문헌·쪽 → 대상·단위·조건 → 후보 기여
→ 강한 비교·대안 → 자료·검증 방법 → 반증 조건 → 현재 근거 상태
문제정의 문안·대응표·기여 종류

이론·가설·문항·표본·분석을 연결하기

설명할 결과와 분석단위, 행위 주체·시점을 먼저 고정하고 이론·측정·추론을 점검합니다.

  1. 이론 후보: 결과·메커니즘·단위·시점·필요 자료를 비교하고 원전과 선택 이유를 연결합니다.
  2. 가설: 개념 정의, 관계가 예상되는 이유, 원문·반례, 조건과 H ID를 연결합니다. 가설이 적절하지 않으면 RQ로 설계합니다.
  3. 문항: 원척도 위치·문항 ID·응답형식과 번역·축약·수정 상태를 기록합니다. 의도/행동·수용/지속사용·비용 부담자/이용자를 구분합니다.
  4. 표본: 최소 의미 효과(SESOI) 또는 정밀도, 효과의 출처·불확실성, 탈락·군집, 모집 N/분석 N, 수집 종료 기준을 기록합니다.
  5. 분석: 주·부 결과, 제외·결측·모형·다중검정·강건성을 계획하고 변경 이유·시점·결과 열람 여부를 남깁니다.
실제 자료가 없으면 계획만 작성합니다. 표본 수의 보편적 기본값을 두지 않습니다. PCA 근사 지표·복합점수 회귀는 정식 CFA·SEM·인과검증을 대신하지 않습니다. 문항표 형식 검사와 측정 타당성, 분석 실행과 가설 지지를 구분합니다.
이론·문항·표본·분석계획 표측정 상세 안내

원문에서 확인한 범위만 근거로 사용하기

문헌 ID·판본과 실제 읽은 페이지를 연결하고 주장에 쓰는 숫자·표·수식·조건을 대조합니다.

  1. 문헌 식별: 서지·DOI·파일·판본을 확인합니다. 해시는 실제 계산한 경우만 적습니다.
  2. 추출과 판독: 텍스트를 먼저 추출하고 필요한 판독 불량 페이지만 OCR합니다. 원시 추출본과 교정본을 보존합니다.
  3. 위치 연결: PDF 쪽과 인쇄 쪽, 절·표의 행/열·각주·수식 위치를 구분합니다.
  4. 주장 대조: 소수점·부호·단위·표본 수·비교 조건과 OCR 교정 전후를 페이지 이미지로 확인합니다.
  5. 한계 인계: 읽은 범위·판독 불가·미확인 위치와 사용 가능한 주장 범위를 남깁니다.
문헌 ID·판본 → PDF 쪽 / 인쇄 쪽 → 절·표·수식
→ 사용할 주장·비교 조건 → 대조 결과 → 읽은 범위·미확인 위치
다운로드·텍스트 추출·OCR는 원문검수 완료가 아닙니다. fulltext_reviewed는 실제 원본 파일의 SHA-256 해시·판본과 실제 읽은 범위·페이지를 함께 기록한 경우에만 부여합니다. 해시 미계산 시 독해 범위와 확인한 주장은 기록하되 이 상태명 부여는 보류합니다. 일부 대조를 문서 전체 검수로 확대하지 않습니다.
주장–페이지 근거표·OCR 교정 장부

수정과 다음 단계의 입력을 함께 남기기

작성된 파일의 존재, 기록 무결성, 실제 실행, 원문 검토, 사람의 승인은 서로 다른 상태입니다.

실제 수행 범위

무엇을 읽고 실행했는지, 어떤 문헌·자료·판본을 사용했는지와 결과물을 연결합니다.

리뷰·수정·재검토

의견별 근거, 수정 위치, 남은 제한, 재검토 결과를 기록합니다. 모의 검토를 실제 지도교수 승인으로 표시하지 않습니다.

변경 영향

원문·자료·RQ·설계가 바뀌면 영향을 받는 주장·표·분석·원고를 다시 확인합니다. 이전 기록은 보존합니다.

다음 단계 입력: 문제정의·설계표, 문헌 ID·판본·근거 위치, 실제 결과 파일, 검토 상태·제한, 추가 확인할 사항을 함께 전달합니다.

직접 채워 쓰는 공통 작업지

작업 범위, 문제정의 문단, 공백–RQ–기여표, 이론·문항표, 표본·분석계획, 원문 근거·OCR 교정, 혼합연구 연결, 리뷰·인계를 한 파일에 모았습니다.

빈칸과 예시 ID는 검수 결과가 아닙니다. 확보하지 못한 근거는 미확인으로, 실행하지 않은 분석은 미실행으로 남기세요.

2. 저자가 보고한 한계와 내 해석을 나눠 공백–RQ–기여–검증–반증 조건을 연결해 줘.

4. 근거가 없으면 신규성·수치·검수 완료를 만들지 말고 필요한 다음 확인을 적어 줘.
5. 수정한 문안과 연결표, 미확인 사항을 반환해 줘.
