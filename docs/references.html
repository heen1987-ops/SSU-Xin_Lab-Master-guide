  • UNSW: 문헌검토 — 질문을 중심으로 문헌을 찾고 평가·종합해 서술하는 방법.
  • UNSW: 학위논문 쓰기 — 개요와 장별 역할을 생각하는 자료. 오래된 안내이므로 학교 서식이나 특정 분량의 근거로 사용하지 않습니다.
  • APA: 본문 인용 — APA를 선택한 원고의 직접 인용·바꿔쓰기·재인용 규칙. 모든 전공에 APA를 강제하는 기준은 아닙니다.

사례의 원자료

초안에서 제출본까지는 저자 제공 보관 폴더의 김희섭 석사논문 판본을 대조한 사례입니다.

장별 작성은 같은 제출본의 서론·관련연구·방법·결과·결론에서 7개 문단을 발췌하고 문단 구성과 집필 순서를 설명합니다. 원문 발췌와 작성 안내를 구분하고, 각 문단에 절 번호·본문 쪽수·PDF 쪽수를 표시했습니다.

비교 자료 사례에서 사용한 범위
‘이전 석사논문 연구자료’의 1차 초안 HWP 연구 목적·범위·연구문제, 방법, 결과 장의 작성 상태
2·4·6·7차 초안 HWPX와 중간 PDF 제목·방법·구성의 변화 대조
‘디콜렉션 제출본’의 20260625 PDF, 111쪽 최종 비교 기준. 각 사례에 본문 쪽수와 PDF 쪽수를 병기

초안의 차수는 보관된 파일명을 따랐습니다. 모든 판본의 작성 순서를 복원하거나, 실제 심사위원의 수정 지시와 작성자의 의도를 확인한 것은 아닙니다. 수치는 제출본의 보고를 옮겼으며 원자료를 재분석하거나 실험을 재실행하지 않았습니다. 개인 보관 초안과 서명·인준서 원본은 이 사이트에 게시하지 않습니다.

기존 저장소에 공개된 김희섭 석사논문 PDF는 위 20260625 파일과 동일한 판본입니다. 사례에 적힌 PDF 쪽수로 해당 내용을 찾아볼 수 있습니다.

보관된 작성 지침과 강의자료

학업영역의 학위논문 작성 안내서와 2026-1학기 온라인 제출 매뉴얼은 서식·제출 점검의 참고자료로 대조했습니다. 기한과 제출 서류는 현재 학기 공지를 우선합니다.

실증논문 특강의 「과학적 조사와 연구」, 「연구모형과 가설설정」, 「자료수집 및 설문지 작성」, 「표본선정과 척도」, 「타당성과 신뢰성」, 「논문작성의 개요」, 「논문의 구성과 학술지와 학위논문의 차이」는 질문–측정–자료–분석–집필의 연결을 검토하는 데 참고했습니다. 강의자료의 특정 예시나 통계 기준을 모든 연구의 의무로 옮기지는 않았습니다. 강의 원본은 이 사이트에서 재배포하지 않습니다.
